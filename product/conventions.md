# Конвенции написания

Единый стандарт того, *как* пишется документация. Написан нейтрально —
переносится в любой проект без изменений.

## Слог

- **Действие вперёд.** Пиши «как поступить», а не «что я думаю».
  Инструкция, а не размышление.
- **Кратко.** Убирай воду. Одна мысль — одно предложение.
- **Понятно без автора.** Читатель может не знать контекста момента
  (в т.ч. это будущий ты или наследник). Не опирайся на «и так понятно».
- **Прямо.** Если чего-то делать не стоит — так и скажи, без обтекаемости.

## Структура

- Заголовки `##` / `###` — по смысловым блокам, а не для красоты.
- Списки — для перечислений и шагов. Таблицы — для сопоставлений
  (вариант | признак | следствие).
- Один документ — одна тема. Разрослось — дели.

## Оформление

- Markdown, `.md`.
- Внутренние ссылки — wikilinks без пути: `[[Название]]`.
- Коллауты Obsidian (`> [!tip]`, `> [!danger]`) — для акцентов, по делу.
- Не ломать существующее оформление и авторский стиль при правках.

## Frontmatter

Три поля, единые для всех документов:

```yaml
---
created: ГГГГ-ММ-ДД
updated: ГГГГ-ММ-ДД
summary: одна строка — о чём документ
---
```

`updated` обновляется при каждом содержательном изменении и служит
сигналом свежести.

## Язык

Русский по умолчанию. Термины-оригиналы (English) — в скобках, если
это часть системы (`Название (English)`).
