# Словарь

| Термин                      | Значение                                                                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Свод**                    | Всё хранилище целиком — личная операционная система жизни.                                                                     |
| **Плейбук**                 | Дистиллированный документ-инструкция «как лучше поступить». Стабилен, готов к применению.                                      |
| **Домен**                   | Тематическая папка верхнего уровня (`Business`, `Job`, `M-F`, …) — раздел жизни, внутри которого лежат плейбуки.               |
| **Исследование (research)** | Датированный разбор темы из проверенных источников. Сырьё, из которого рождается или обновляется плейбук. Живёт в `research/`. |
| **Мета-документ**           | Документ о самом своде (`product/`): видение, скоуп, словарь, конвенции.                                                       |
| **Конвенции**               | Правила того, как пишется документация (`conventions.md`). Проектно-нейтральны.                                                |
| **CLAUDE.md**               | Служебный файл с правилами для ассистента. Корневой — общий; вложенный в домене — правила этого домена.                        |

## Правило термина

Новые понятия сначала заводятся здесь, потом используются в документах.
Если термин переименован — старые исторические записи (research прошлых
дат) не переписываются, там он остаётся как факт на момент написания.
