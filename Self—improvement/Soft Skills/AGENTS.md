# Soft Skills

## Назначение
Справочные материалы для прокачки навыков. Сейчас — английская грамматика.

## English (`English/`)
Справочник в виде таблиц. Правила:
- Формат таблиц: строки — аспекты/группы, столбцы — Past / Present / Future.
- Каждая ячейка: формула + пример на английском (курсив) + перевод.
- Неправильные глаголы: колонки Infinitive | Past Simple | Past Participle | Перевод,
  порядок по алфавиту. Варианты форм через `/` (burnt / burned).
- Не менять грамматические факты без сверки. Пополнять по образцу существующих строк.
