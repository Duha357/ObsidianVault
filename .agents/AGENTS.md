# .agents — раскладка и именование

Канон кросс-агентных материалов: правила (`rules`), процедуры (`skills`), справочники (`references`). Claude Code видит их через junctions `.claude/rules` → `.agents/rules` и `.claude/skills` → `.agents/skills`.

Читай перед созданием, переименованием или переносом любой сущности внутри `.agents/`.

## Структура

```
.agents/
  AGENTS.md                                  # этот файл
  CLAUDE.md                                  # @AGENTS.md, для Claude Code
  rules/<тема>/RULE.md                       # правило
  skills/<имя>/SKILL.md                      # процедура
  references/
    examples/<владелец>/EXAMPLE.md           # образцы оформления
    sources/<владелец>/SOURCE.md             # каталоги источников
```

## Правила

- Папка на сущность, внутри один файл роли.
- Имя папки — тема правила, имя скилла, имя владельца справочника.
- Имя файла — роль капсом: `RULE.md`, `SKILL.md`, `EXAMPLE.md`, `SOURCE.md`.
- Владелец справочника — правило или скилл с тем же именем папки.
- Справочники живут только в `references/`, рядом с владельцем их не кладут.
  - Причина: `.claude/rules` обнаруживается рекурсивно, любой `.md` под `.agents/rules/` грузится в контекст на старте каждой сессии.
  - `.agents/references/` вне этого дерева — читается по ссылке, когда понадобился.
- В файле сущности — правило или процедура; объёмные образцы, каталоги и большие таблицы — в справочник.
- Ссылки между файлами — путями от корня репо (`.agents/rules/ai-output/RULE.md`).
- Шапка справочника — обратная ссылка на владельца.
- **Не:**
  - Класть файлы напрямую в `rules/`, `skills/`, `references/examples/`, `references/sources/`.
  - Использовать относительные ссылки: файлы переносят, относительные ломаются.
  - Дублировать в справочнике содержание владельца.

## Новая сущность

1. Создать папку по имени сущности в нужной категории.
2. Положить внутрь файл роли.
3. Прописать ссылку от владельца на справочник и обратную ссылку в шапке справочника.
4. Для правил и скиллов — добавить строку в корневой `AGENTS.md`, разделы «Процедуры (скиллы)» и «Правила оформления (rules)».
5. Перенос или переименование — обновить все ссылки на старый путь (`rg "<старый путь>"`).
