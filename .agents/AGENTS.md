## Правила

Прочитать и применять сразу. Если дальнейшими инструкциями или пользователем не указано иное.

- Текущий раздел `## Правила` наследует все `## Правила` в `AGENTS.md` уровнем выше в текущем проекте.
- Любое несоответствие правилам — не исправлять. Явно сообщить!
- Спорные случаи не решать самому. Явно сообщить!
- Перед выдачей проверять соответствие `## Правила`, `## Архитектура`.
- Папка на сущность, внутри один файл роли.
- Имя папки — тема правила, имя скилла, имя владельца справочника.
- Имя файла — роль капсом: `RULE.md`, `SKILL.md`, `EXAMPLE.md`, `SOURCE.md`.
- Владелец справочника — правило или скилл с тем же именем папки.
- Справочники живут только в `.agents/references/`, рядом с владельцем их не кладут.
	- Причина: Не требуются для загрузки в контекст на старте каждой сессии.
	- `.agents/references/` читается по ссылке в `.md` документе, при его чтении.
- В файле сущности — правило или процедура; объёмные образцы, каталоги и большие таблицы — в справочник.
- Шапка справочника — обратная ссылка на владельца.
- **Не:**
	- Дублировать унаследованные правила в текущем разделе `## Правила`.
	- Класть файлы напрямую в `.agents/rules/`, `.agents/skills/`, `.agents/references/examples/`, `.agents/references/sources/`.
	- Игнорировать правила в `.agents/rules/*`
	- Дублировать в справочнике содержание владельца.
- **Исключение:**
	- Заданные эталоном `## Правила` дублировать допускается.

## Архитектура

- `.agents/AGENTS.md` — общие инструкции для ИИ агентов.
- `.agents/CLAUDE.md` — инструкции для Claude Code.
- `.agents/README.md` — общие инструкции для людей.
- `.agents/rules/<тема>/RULE.md` — общие правила для ИИ агентов.
- `.agents/skills/<имя>/SKILL.md` — общие скиллы для ИИ агентов.
- `.agents/references/examples/<владелец>/EXAMPLE.md` — общие образцы оформления и эталоны для ИИ агентов.
- `.agents/references/sources/<владелец>/SOURCE.md` — общие каталоги источников и справочников для всех сущностей текущего блока `## Архитектура`.

## Новая сущность

1. Создать папку по имени сущности в нужной категории.
2. Положить внутрь файл роли.
3. Прописать ссылку от владельца на справочник и обратную ссылку в шапке справочника.
4. Для правил и скиллов — добавить строку в корневой `AGENTS.md`, разделы «Процедуры (скиллы)» и «Правила оформления (rules)».
5. Перенос или переименование — обновить все ссылки на старый путь (`rg "<старый путь>"`).
