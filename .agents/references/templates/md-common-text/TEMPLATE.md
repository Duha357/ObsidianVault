## Правила

После открытия текущего документа — прочитай и постоянно применяй при работе с целевой сущностью! Если дальнейшими инструкциями или пользователем не указано иное.

- Текущий `## Правила` наследует все `## Правила` в `AGENTS.md` уровнем выше в папочной иерархии текущего проекта.
- Любое несоответствие целевой сущности текущего документа, разделам текущего документа и (если есть) разделам унаследованным текущим документом — не исправлять. Явно сообщить!
- Спорные случаи не решать самому. Явно сообщить! Предложить варианты решения.
- Перед выдачей проверять соответствие разделам текущего документа и (если есть) разделам унаследованным текущим документом.
- Эталон задаёт общую часть документа: свойства, разделы `## Содержание` и `## Назначение`, разделители, ссылки возврата.
- Эталоны:
	- Раздел внутри блока эталона — раздел будущего документа.
	- **Не:**
		- Считать содержание примеров—эталонов разделами этого файла.
		- Проверять состав разделов этого файла по содержанию примеров—эталонов.
- **Не:**
	- Дублировать унаследованные правила в текущем разделе `## Правила`.
- **Исключение:**
	- Заданные эталоном `## Правила` дублировать допускается.

## Эталоны

Свойства `.md` документа:

```markdown
---
name: {Обычно имя самого документа. Если инструкция `CAPS.md`/`RULE.md`/`SKILL.md` и т.д., то имя папки в котором лежит документ.}
description: {Перечисление триггеров `Когда документ применяется?`. Без пояснений. Начинается с `При работе с ...`. Минимум 1 пример. Рекомендуется минимум 4 примера. Примеры не узкоспециализированы. Включает только триггеры.}
paths: {Замена. Список масок, при работе с которыми документ попадает в контекст. Каждая маска с новой строки, в двойных кавычках, путь от корня репозитория. Не добавляется, если документ не правило или действует всегда.}
{Замена. Дополнительные свойства. Если требуются. По аналогии с эталоном.}
---
```

## Примеры: плохо

Свойства:

```markdown
---
name: RULE
description: Правило про оформление документов, применяется всегда и везде.
owner: Иванов
---
```

Путь:

```markdown
- Правило — @rules/md-common-text/RULE.md.
- Эталон — ../templates/md-common-text/TEMPLATE.md.
```

Разделители и возврат:

```markdown
## Назначение

- Даёт эталон общей части документа.
## Правила
```

Вложенность списка:

```markdown
- Свойства:
  - `name`.
  - `description`.
```

Заголовки подблоков:

```markdown
## Эталоны

### Эталон 1. Быстрый ответ
```
