## Правила

Прочитать и применять сразу. Если дальнейшими инструкциями или пользователем не указано иное.

- Текущий `## Правила` наследует все `## Правила` в `AGENTS.md` уровнем выше в папочной иерархии текущего проекта.
- Любое несоответствие целевой сущности текущего документа, разделам текущего документа и (если есть) разделам унаследованным текущим документом — не исправлять. Явно сообщить!
- Спорные случаи не решать самому. Явно сообщить! Предложить варианты решения.
- Перед выдачей проверять соответствие разделам текущего документа и (если есть) разделам унаследованным текущим документом.
- Процедуры подключения агента брать у владельца.
- Новый агент:
	- Новая строка в `## Реестр агентов`.
	- Новый раздел `## Механизмы {Замена. Называние агента}`.
- Непроверенный механизм помечается `<!-- TODO(пользователь): ... -->`, а не пишется по памяти.
- **Не:**
	- Повторять здесь процедуры владельца.

## Механизмы Claude Code

| Что | Когда попадает в контекст | Чем задаётся |
|-----|---------------------------|--------------|
| `CLAUDE.md` в корне | старт сессии, целиком | сам файл |
| `CLAUDE.md` в подпапке | обращение к файлам этой подпапки | сам файл |
| `.claude/rules/*.md` без `paths` | старт сессии, целиком | сам файл |
| `.claude/rules/*.md` с `paths` | чтение файла по маске | свойство `paths` |
| `.claude/skills/*/SKILL.md` | `description` всегда, тело при вызове | свойство `description` |
| Хук `SessionStart` | старт сессии; stdout уходит в контекст | `.claude/settings.json` |
| Хук `UserPromptSubmit` | каждое сообщение; stdout уходит в контекст | `.claude/settings.json` |
| Хук `PostToolUse` | после вызова инструмента; `exit 2` шлёт stderr агенту | `.claude/settings.json` |
| Хук `PreToolUse` | до вызова; может запретить вызов | `.claude/settings.json` |

- Simlincs/Junction (зависит от системы) `.claude/rules` → `.agents/rules` и `.claude/skills` → `.agents/skills`: канон один, читается обоими путями.
- Хук в shell-форме исполняется через `sh -c` на Linux и Git Bash на Windows. Один скрипт покрывает обе системы.
- Переменная `${CLAUDE_PROJECT_DIR}` указывает на корень проекта и не смещается в worktree.
