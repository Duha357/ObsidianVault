# Образцы результата для скилла `researcher`

Образцы показывают оформление результата. Правило оформления — `ai-output` (`.agents/rules/ai-output/RULE.md`), специфика исследования — раздел «Оформление» в `.agents/skills/researcher/SKILL.md`.

## Пример: плохо

Результат прозой:

```markdown
Большинство экспертов сходится, что подход работает, хотя есть и критика, а данные по рынку противоречивы.
```

Вывод без трассировки:

```markdown
- Подход повышает выручку [moderate].
```

Источники, сжатые в строку:

```markdown
Источники: <отчёт>, <год>, вес 7; <постмортем>, <год>, вес 6.
```

Маркер уверенности удалён при сжатии:

```markdown
- Подход снижает отток.
```

Ключевой вывод на источнике с неполными метаданными:

```markdown
- Подход повышает выручку [moderate] — <блог>, автор не указан, дата не указана.
```

Нормативный документ как доказательство эффекта:

```markdown
- Стандарт <номер> требует X, следовательно X снижает число дефектов [high].
```

Вывод оторван от своих источников при разделении на части:

```markdown
Часть 1 из 2

- <тезис> [moderate].
```

## Пример: хорошо

Вывод с трассировкой и уверенностью:

```markdown
- <тезис> [moderate] — <отчёт ассоциации>, <постмортем компании>.
```

Источники таблицей:

```markdown
| Источник | Класс | Роль | Дата | Вес | SIFT |
|---|---|---|---|---|---|
| <отчёт ассоциации> | Отраслевые отчёты | агрегатор | <дата> | 7 | пройдена |
| <постмортем компании> | Кейсы | первичный | <дата> | 6 | пройдена |
```

Разграничение нормы и эффекта:

```markdown
- Стандарт <номер> требует X [high] — нормативный источник.
- Влияние X на число дефектов — <вывод> [low] — 2 кейса, эксперимента не найдено.
```

Малая выборка:

```markdown
- Негативный кейс не найден при 3 источниках. Уверенность снижена до low.
```

Многочастный результат:

```markdown
Часть 1 из 2

## Выводы

- <тезис> [moderate] — <отчёт ассоциации>, <постмортем компании>.
```
