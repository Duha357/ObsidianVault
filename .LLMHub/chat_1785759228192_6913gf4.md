## Методы (def)

В Scala функции, объявленные через def, являются методами — членами класса или объекта.

object LibraryUtils:  
  def countPages(pages: Int): Int =  
    pages * 2

Особенности метода:

- объявляется с помощью ключевого слова def;
    
- принадлежит классу или объекту;
    
- не является значением сам по себе;
    
- вычисляется при каждом вызове.
    

Вызов:

LibraryUtils.countPages(150)

Метод — это поведение, связанное с типом.

---

## Именованные функции как значения

В Scala функция может быть значением.

Тип функции записывается как:

(Int) => Int

Пример:

val increasePages: Int => Int =  
  (pages: Int) => pages * 2

Здесь:

- (pages: Int) => pages * 2 — лямбда-выражение;
    
- square — значение, содержащее функцию.
    

Такое значение является объектом, реализующим трейт Function1[Int, Int].

---

## Анонимные функции (лямбды)

Базовый синтаксис:

(bookCount: Int) => bookCount * 2

Если тип можно вывести, его можно опустить:

bookCount => bookCount * 2

Использование с коллекциями:

List(100, 200, 300).map(bookPages => bookPages + 50)

---

## Синтаксический сахар

Если параметр используется один раз, можно применить сокращённую форму с _:

List(100, 200, 300).map(_ + 50)

Это эквивалентно:

bookPages => bookPages + 50

Важно:

- _ можно использовать, если каждый параметр встречается ровно один раз;
    
- при нескольких параметрах используются несколько подчеркиваний.
    

Пример:

val totalPages: (Int, Int) => Int = _ + _

---

## Метод vs функция

Это принципиально важное различие.

### Метод

def addBooks(firstShelf: Int, secondShelf: Int): Int = firstShelf + secondShelf

- принадлежит классу или объекту;
    
- не является объектом;
    
- не имеет типа FunctionN напрямую.
    

---

### Функциональное значение

val addBooksFn: (Int, Int) => Int = (firstShelf, secondShelf) => firstShelf + secondShelf

- является объектом;
    
- имеет тип Function2[Int, Int, Int];
    
- может передаваться как аргумент.
    

---

## Eta-расширение (преобразование метода в функцию)

Метод можно преобразовать в функцию.

def calculateBooks(boxes: Int, booksPerBox: Int): Int = boxes * booksPerBox  
  
val calculateBooksFn = calculateBooks _

Подчёркивание инициирует eta-расширение.

Теперь calculateBooksFn имеет тип:

(Int, Int) => Int

В Scala 3 часто eta-расширение происходит автоматически, если контекст ожидает функцию:

List(100, 200, 300).map(LibraryUtils.countPages)

Компилятор преобразует метод в функцию.

---

## Практическое сравнение

  

|   |   |   |
|---|---|---|
|Характеристика|Метод (def)|Функция (val f = ...)|
|Является значением|Нет|Да|
|Принадлежит классу|Да|Может быть любым значением|
|Может передаваться напрямую|Через eta|Да|
|Тип|Не FunctionN|FunctionN|

  

---

## Использование в коллекциях

Функции активно используются в API коллекций:

val bookPages = List(100, 200, 300)  
  
bookPages.map(_ + 10)  
bookPages.filter(_ > 200)  
bookPages.foldLeft(0)(_ + _)

Здесь функции передаются как значения.

	- Пункты начинаются с большой буквы.
	- Пункты заканчиваются точкой.

- Числа, пути, команды, имена файлов — всегда явно.
