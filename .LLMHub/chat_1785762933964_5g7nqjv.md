## Функции высшего порядка (Higher-Order Functions)

##### Определение

Функция называется функцией высшего порядка, если она:

- Принимает функцию в качестве аргумента.
- Возвращает функцию как результат.
- Или делает и то, и другое.

Это естественное следствие того, что в Scala функции являются значениями.

---

## Передача функции как аргумента

Функция передаётся в другую функцию как аргумент, как и любое другое значение.

> [!example]- Пример: Передача функции как аргумента
> `applyToPages` принимает функцию `transform` и применяет её к `pages` дважды.
>
> Вызов `applyToPages(addExtraPages, 150)` вернёт `190`.
>
> ```scala
> def applyToPages(transform: Int => Int, pages: Int): Int =
>   transform(transform(pages))
>
> val addExtraPages: Int => Int = _ + 20
>
> applyToPages(addExtraPages, 150) // 190
> ```
>
> Пример показывает: передачу функции в качестве аргумента.

---

## Возврат функции из функции

Функция может возвращать другую функцию.

> [!example]- Пример: Возврат функции из функции
> `pagesMultiplier` возвращает функцию, умножающую страницы на коэффициент.
>
> Вызов `doublePages(120)` вернёт `240`.
>
> ```scala
> def pagesMultiplier(factor: Int): Int => Int =
>   (pages: Int) => pages * factor
>
> val doublePages = pagesMultiplier(2)
> doublePages(120) // 240
> ```
>
> Пример показывает: возврат функции и замыкание на значении `factor`.

## Функции высшего порядка в стандартной библиотеке

Большинство операций над коллекциями являются функциями высшего порядка.

##### map

`map` применяет переданную функцию к каждому элементу коллекции и собирает результаты в новую коллекцию.

> [!example]- Пример: map
> `map` удваивает каждый элемент списка.
>
> Результат — `List(2, 4, 6)`.
>
> ```scala
> List(1, 2, 3).map(_ * 2)
> ```
>
> Пример показывает: передачу функции преобразования в `map`.

##### filter

`filter` принимает предикат и оставляет элементы, для которых он истинен.

> [!example]- Пример: filter
> `filter` оставляет только чётные элементы списка.
>
> Результат — `List(2, 4)`.
>
> ```scala
> List(1, 2, 3, 4).filter(_ % 2 == 0)
> ```
>
> Пример показывает: передачу предиката в `filter`.

##### foldLeft

`foldLeft` принимает функцию аккумуляции и сворачивает коллекцию в одно значение.

> [!example]- Пример: foldLeft
> `foldLeft` суммирует элементы списка, начиная с нуля.
>
> Результат — `6`.
>
> ```scala
> List(1, 2, 3).foldLeft(0)(_ + _)
> ```
>
> Пример показывает: передачу функции аккумуляции в `foldLeft`.

Вся функциональная обработка коллекций основана на функциях высшего порядка.

## Композиция функций

Композиция — это построение новой функции из нескольких простых.

##### Математическая идея

Если есть функции:

- `f: A => B`.
- `g: B => C`.

То их композиция создаёт функцию `A => C`.

---

## andThen

Метод `andThen` выполняет функции слева направо.

> [!example]- Пример: andThen
> `double` и `increment` объединяются в конвейер: сначала удвоение, затем прибавление единицы.
>
> Вызов `pipeline(3)` вернёт `7`.
>
> ```scala
> val double: Int => Int = _ * 2
> val increment: Int => Int = _ + 1
>
> val pipeline = double.andThen(increment)
>
> pipeline(3) // (3 * 2) + 1 = 7
> ```
>
> Пример показывает: построение конвейера через `andThen`.

Семантика:

```scala
result = increment(double(x))
```

Это удобная форма построения «конвейера» обработки данных.

---

## compose

Метод `compose` выполняет функции справа налево.

> [!example]- Пример: compose
> `increment` и `double` объединяются через `compose`.
>
> Вызов `composed(3)` вернёт `7`.
>
> ```scala
> val composed = increment.compose(double)
>
> composed(3) // 7
> ```
>
> Пример показывает: тот же результат, что и у `andThen`, при обратном порядке записи.

Семантика:

```scala
result = increment(double(x))
```

Разница в порядке записи.

---

## Построение конвейера обработки

Композиция позволяет собирать сложную логику из простых блоков.

> [!example]- Пример: Конвейер обработки строк
> Три функции объединяются в конвейер обработки названия книги.
>
> Вызов `processBookTitle("  dune  ")` вернёт `"Library: DUNE"`.
>
> ```scala
> val trimTitle: String => String = _.trim
> val toUpperCase: String => String = _.toUpperCase
> val addLibraryTag: String => String = "Library: " + _
>
> val processBookTitle =
>   trimTitle
>     .andThen(toUpperCase)
>     .andThen(addLibraryTag)
>
> processBookTitle("  dune  ")
> // "Library: DUNE"
> ```
>
> Пример показывает: сборку сложной обработки из простых функций.

Преимущества:

- Декларативность.
- Повторное использование функций.
- Тестируемость отдельных этапов.
- Линейный поток данных.

## Связь с for-comprehension и монадической композицией

Функции высшего порядка лежат в основе:

- `map`.
- `flatMap`.
- `for-comprehension`.
- Обработка `Option`, `Either`, `List`.

Композиция функций — частный случай более общей идеи композиции вычислений.
