# Чистые функции, рекурсия и хвостовая рекурсия 

---

## Чистые функции (Pure Functions)

### Определение

Функция считается чистой, если:

1. Она детерминирована — при одинаковых входных параметрах всегда возвращает один и тот же результат.
    
2. Она не имеет побочных эффектов — не изменяет внешнее состояние и не зависит от него.
    

Пример чистой функции:

def calculateTotalPages(firstBookPages: Int, secondBookPages: Int): Int = firstBookPages + secondBookPages

Пример нечистой функции:

var booksProcessed = 0  
  
def processBook(): Int =  
  booksProcessed += 1  
  booksProcessed

Здесь результат зависит от внешнего состояния (booksProcessed).

---

## Побочные эффекты

К побочным эффектам относятся:

- изменение переменных;
    
- ввод/вывод (печать в консоль, работа с файлами);
    
- сетевые вызовы;
    
- изменение коллекций;
    
- бросание исключений.
    

Чистая функция работает только со своими аргументами и возвращает значение.

---

## Преимущества чистоты

### Предсказуемость

Функцию можно рассматривать как математическое отображение.

### Тестируемость

Нет необходимости в моках глобального состояния.

### Потокобезопасность

Отсутствие изменяемого состояния упрощает параллельное выполнение.

### Композиция

Чистые функции легко комбинируются через map, flatMap, fold.

---

## Рекурсия

В функциональном стиле рекурсия является основной альтернативой циклам.

Императивный стиль:

def totalPages(n: Int): Int =  
  var sum = 0  
  for i <- 1 to bookCount do  
    sum += i * 100  
  sum

Функциональный стиль:

def totalPages(n: Int): Int =  
  if bookCount <= 0 then 0  
  else bookCount + totalPages(bookCount - 1)

Рекурсия выражает решение декларативно — через определение задачи через более простую версию самой себя.

---

## Проблема переполнения стека

Каждый рекурсивный вызов занимает место в стеке вызовов.

При глубокой рекурсии возможна ошибка:

java.lang.StackOverflowError

Например:

totalPages(1000000)

Если рекурсивный вызов не является хвостовым, стек будет расти.

---

## Хвостовая рекурсия

### Определение

Рекурсия называется хвостовой, если рекурсивный вызов — это последнее действие функции.

Нехвостовая версия:

def totalPages(bookCount: Int): Int =  
  if bookCount <= 0 then 0  
  else bookCount * 100 + totalPages(bookCount - 1)

После вызова totalPages(bookCount - 1) происходит операция сложения — значит, это не хвостовая рекурсия.

---

### Хвостовая версия

import scala.annotation.tailrec  
  
@tailrec  
def accumulatePages(remainingBooks: Int, total: Int = 0): Int =  
  if remainingBooks <= 0 then total  
  else accumulatePages(remainingBooks - 1, total + 100)

Здесь рекурсивный вызов — последнее действие.

Состояние (аккумулятор) передаётся параметром.

---

## Tail Call Optimization (TCO)

Scala (на JVM) оптимизирует хвостовую рекурсию:

- стек не растёт;
    
- рекурсия преобразуется в цикл с изменяемой переменной на уровне байткода;
    
- достигается эффективность императивного цикла.
    

Важно: JVM поддерживает только самохвостовую оптимизацию (self-recursion). Взаимная рекурсия не оптимизируется автоматически.

---

## Аннотация @tailrec

Аннотация:

@tailrec

заставляет компилятор проверить, что функция действительно хвостовая.

Если оптимизация невозможна, компилятор выдаст ошибку.

Это:

- защищает от случайной потери оптимизации;
    
- гарантирует безопасность по стеку;
    
- делает намерение разработчика явным.
    

Рекомендуется всегда использовать @tailrec, когда функция должна быть хвостовой.

## Правила

Перед выдачей проверка соответствия правилам.

- Сохранять доминирующий язык пользователя.
- Сжимать стиль, а не язык.
- Сохранять технические фрагменты: термины, код, имена API, команды CLI и точные строки ошибок дословно, на том же языке.
- Заголовки:
	- Основные блоки — H2.
	- Подблоки — H5.
- Пункты списка:
	- Вместо перечислений в прозе.
	- Вложенность — максимум 3 уровня.
	- Один пункт = один факт/действие/вывод.
	- Пункты начинаются с большой буквы.
	- Пункты заканчиваются точкой.
	- Максимум 2 предложения: первое — факт, второе — пояснение (если нужно).
	- Последовательности/порядок — нумерованными подпунктами: один шаг = один подпункт, независимо от уровня и количества.
	- Негативные — группируются подпунктами в пункт `**Не:**`.
	- Перечисляющие ситуации-исключения — группируются подпунктами в пункт `**Исключение:**`.
	- Порядок в списке:
	    1. Положительные пункты.
	    2. `**Не:**`.
	    3. `**Исключение:**`.
	- Обычные списки нумеруются на первом уровне, если пунктов больше 5 и нет `**Не:**`/`**Исключение:**`.
	- **Исключение:**
	    - Короткие перечисления однородных терминов внутри пункта (через запятую или /).
- Телеграфный стиль допустим: глагол + объект.
- Разделители `---` делят заголовки H2.
- Числа, пути, команды, имена файлов — всегда явно.
- Стрелка `->` или `→` — только для пары «замена/соответствие» (X -> Y).
- Заменять длинные формулировки короткими:
	- доктор -> врач.
	- дискуссия -> спор.
	- аварийное завершение работы приложения -> краш.
	- extensive -> big.
	- implement a solution for -> fix.
- Удалять:
	- Преамбулы (итак/давайте разберём/отличный вопрос и т.д.).
	- Заключения (надеюсь, помогло/если что — обращайтесь и т.д.).
	- Связующие слова (например стоит отметить/важно понимать/как видим/при этом и т.д.).
	- Артикли (a/an/the).
	- Слова-заполнители (просто/как бы/just/basically/actually/simply и т.д.).
	- Любезности (всё верно/действительно/sure/really/certainly/of course/happy to и т.д.).
	- Оговорки (скорее всего/возможно/на всякий случай и т.д.).
	- **Исключение:**
	    - Фрагменты фраз, оставшиеся после удаления. Предложение перефразируется.
	    - `и т.д.` как маркер открытого перечисления.
	    - Критично для смысла.
	    - Итоговый текст вводит в заблуждение.
- **Не:**
	- Писать развёрнутые предложения там, где хватает телеграфного стиля.
	- Давать неточные определения («примерно», «где-то в» и т.д.).
	- Делить заголовки H5 разделителем `---`.
	- Использовать навязанные другими инструкциями вступительные или статусные фразы.
	- Называть и объявлять стиль/правила.
	- Ссылаться на себя (самореференция).
	- Сжимать перечисления шагов и последовательности в строку символами (->, →, /, запятыми и т.д.).
