## Правила

После открытия текущего документа — прочитай и постоянно применяй при работе с целевой сущностью! Если дальнейшими инструкциями или пользователем не указано иное.

- Текущий `## Правила` наследует все `## Правила` в `AGENTS.md` уровнем выше в папочной иерархии текущего проекта.
- Любое несоответствие целевой сущности текущего документа, разделам текущего документа и (если есть) разделам унаследованным текущим документом — не исправлять. Явно сообщить!
- Спорные случаи не решать самому. Явно сообщить! Предложить варианты решения.
- Перед выдачей проверять соответствие разделам текущего документа и (если есть) разделам унаследованным текущим документом.
- Каждая вложенность — 2 пробела.
- Заголовок подпрограммы:
	- Функции — `is`.
	- Процедуры — `as`.
- Параметры — с новой строки, запятая в начале.
- Типы параметров выравниваются пробелами по самому длинному имени параметра.
- Возвращаемое значение функции кладётся в переменную `result`.
- Перед `return` ставится пустая строка.
- Шапка подпрограммы:
	- Открывается и закрывается строкой `--====================================================================`.
	- Уровень доступа — строка `-- @public` или `-- @private`.
	- Назначение — строка `-- Purpose: `.
	- Блок `-- Important: ` добавляется, если важно что-то знать до чтения.
		- Устаревшая подпрограмма — в блоке указывается `DEPRECATED!!!`.
- Генерируемый код (строка для `execute immediate`, `dbms_sql` и т.д.) начинается с `chr(10)`.
	- Причина: в логах блок не приклеивается к концу предыдущей записи.
	- Перенос ставится первым слагаемым конкатенации, до открывающего `begin`, `declare` или иного.
- Файл:
	- Заголовок и тело — обязательны оба.
	- Оба лежат в одной папке.
	- Меняются вместе.
- Новые переменные/параметры — в конец и со значением по умолчанию.
- Выбор типа данных:
	- Строка — varchar2.
	- Идентификатор — number.
	- Любое число — number.
	- Булевое — number.
	- Дата — date.
	- Двоичные бинарные данные — blob.
	- Длинные текстовые данные — clob.
	- Объектный тип — имя объектного типа.
	- Строка БД — `...%ROWTYPE`.
	- Константа — объявляется через `constant`.
- Работа с вызовами:
	- Поиск — по имени функции во всех модулях.
	- Имя пакета/функции/процедуры и т.д. может собираться строкой, компилятор такие связи не видит.
	- Искать по имени без префиксов и постфиксов.
- Кросс-модульная работа:
	- Вызовы — только через публичные пакеты чужого модуля.
	- Общая логика выносится в модуль-помощник, не копируется между пакетами.
- Именование:
	- В коде есть исторические отклонения от схемы. Новый код пишется по ней.
	- Соответствует формату CamelCase.
		- **Исключение:**
			- Сокращения — UpperCase (Прим.: API/DPI/XML и т.д.).
			- Правила или пользователь диктуют иное.
	- Файлы:
		- Префикс — имя модуля и подчёркивание: `{Модуль}_...`.
		- Постфикс:
			- `...PKG` — пакеты package.
			- `...DPI` — генерируемые системой типы type.
			- `...API` — переопределяющие `...DPI` типы type.
		- Расширения:
			- `.pks` — заголовок.
			- `.pkb` — тело.
		- Длина имени до расширения — не более 27 символов.
	- Переменные:
		- Способ наименования близок к венгерской нотации.
		- Префикс:
			- Тип данных:
				- Указывается обязательно.
				- `s...` — строка.
				- `id...` — идентификатор. Для идентификаторов — указывается тип number.
				- `n...` — число.
				- `b...` — булевое. Для булевых — указывается тип number.
				- `d...` — дата.
				- `l...` — blob или двоичные данные.
				- `c...` — clob.
				- `o...` — объектный тип.
				- `r...` — строка БД.
			- Уровень доступа:
				- Указывается обязательно.
				- В имени — после типа данных, до имени переменной.
				- Глобальные — `...g...`.
				- Параметры — `...p...`.
				- Локальные — `...v...`.
			- Перечисление/список/кортеж и т.д.:
				- Указывается ситуативно.
				- Обозначается `...a...`.
				- В имени — после типа данных, до уровня доступа.
	- **Не:**
		- Превышать 30 символов в имени до расширения.
- **Не:**
	- Дублировать унаследованные правила в текущем разделе `## Правила`.
	- Ломать публичные сигнатуры. Только дополнять.
- **Исключение:**
	- Заданные эталоном `## Правила` дублировать допускается.
