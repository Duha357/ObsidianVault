### Страдательный залог

| Группа                          | **Past** (Прошедшее)                                                                                                                                                  | **Present** (Настоящее)                                                                                                                                             | **Future** (Будущее)                                                                                                                                            |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Simple**  <br>_(Факт)_        | was / were **+ V3**<br><br>_(The letter was written)_<br>Письмо **было написано**<br>  <br>_(House was built last year)_<br>Дом построили в прошлом году              | am / is / are **+ V3**<br><br>_(The letter is written)_<br>Письмо **написано** <br>  <br>_(House is built every year)_<br>Дом строят каждый год                     | will **be + V3**<br><br>_(The letter will be written)_<br>Письмо **будет написано**<br>  <br>_(House will be built next year)_<br>Дом построят в следующем году |
| **Continuous**  <br>_(Процесс)_ | was / were **being + V3**<br><br>_(The letter was being written)_<br>Письмо **писалось** в тот момент<br>  <br>_(House was being built)_<br>Дом строился в тот момент | am / is / are **being + V3**<br><br>_(The letter is being written)_<br>Письмо **пишется** прямо сейчас<br>  <br>_(House is being built now)_<br>Дом сейчас строится | -                                                                                                                                                               |
| **Perfect**  <br>_(Результат)_  | had **been + V3**<br><br>_(The letter had been written)_<br>Письмо **было уже написано** (к тому моменту)                                                             | have / has **been + V3**<br><br>_(The letter has been written)_<br>Письмо **уже написано**.  <br>  <br>_(House has been built)_<br>Дом уже построили                | will **have been + V3**<br><br>_(The letter will have been written)_<br>Письмо **будет уже написано** (к сроку)                                                 |
