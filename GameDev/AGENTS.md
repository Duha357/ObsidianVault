# GameDev

## Назначение
Материалы по разработке игр. Ядро — система тегирования игр.

## Система тегирования (`Games/Система тегирования.md`)
Эталонная таксономия. Правила:
- Система ортогональна: измерения независимы (Gameplay, Vibe, Visual,
  Technique, Mode и т.д.). Не смешивать измерения.
- Атомизация: сложные теги раскладывать на базовые
  (metroidvania = Metroid + Castlevania; 4X = eXplore/eXpand/eXploit/eXterminate).
- Формат: `Русское название (English)`, синонимы через `|`.
- Цель тегов — складываться в осмысленное предложение об игре.
- Новые теги вводить только с явным местом в структуре измерений.
