### Родовые сценарии и Прошлое

#### Семейная иерархия

_Варианты формулировок:_
- А у тебя мама и папа до сих пор вместе? А папа насколько строгий?

_Цель:_ Выявить наследственный сценарий

| Типаж                                     | Индикатор в ответе                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Гиперконтролирующая**                   | Мама главная, папа подкаблучник/пассивный. ("Я не хочу быть как папа", но повторяет сценарий мамы) |
| **Истероидная натура / Агрессивный боец** | Папа тиран/алкоголик, мама жертва. Девушка ищет похожие сценарии                                   |
| **Гармоничная**                           | Полная семья, здоровая атмосфера, или конструктивный развод без войн. Уважение к отцу              |

#### Независимость от родителей (Лучше понаблюдать, а не спрашивать)

_Варианты формулировок:_
- Ты советуешься с папой/мамой по важным решениям?

_Цель:_ Определить степень взрослости, угрозу вмешательства родни, степень внушаемости со стороны мамы

| Типаж                   | Индикатор в ответе                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| **Пассивная иждивенка** | Мама решает всё. "Я у мамы спрошу". Полная зависимость от родительского мнения                   |
| **Гиперконтролирующая** | Мама вмешивается в семью, дочь позволяет это. Часто повторяет сценарий мамы                      |
| **Гармоничная**         | Уважает родителей, но решения принимает самостоятельно. Главой для неё становится муж, а не мама |

#### Ближайший круг (Лучше понаблюдать, а не спрашивать)

_Варианты формулировок:_
- Семейные ли у тебя подруги?
- С кем ты обычно отдыхаешь? Давно дружите?

_Цель:_ Определить, проблемные ли подруги

| Типаж                                                   | Индикатор в ответе                                                             |
| ------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Импульсивная гедонистка** / **Материальная тунеядка** | Подруги любят тусовки, клубы, сидят на содержании, обсуждают мужчин как ресурс |
| **Истероидная натура**                                  | Подруги часто меняются, либо есть одна "жилетка" для драм                      |
| **Гармоничная**                                         | Подруги замужем, заняты семьей, работой или учебой. Здоровый круг общения      |

#### История расставаний

_Варианты формулировок:_
- Как давно без отношений и почему они закончились?

_Цель:_ Понять динамику отношений

| Типаж                               | Индикатор в ответе                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Истероидная натура (Драма-квин)** | Ушла, потому что "прошла любовь". Была "драма"                                                    |
| **Импульсивная гедонистка**         | Партнеры меняются быстро. Нет периода одиночества                                                 |
| **Агрессивный боец**                | Ушла, потому что "достал" / "тряпка". Со скандалами                                               |
| **Деструктивный спасатель**         | Ушла от "алкоголика/тирана/наркомана"                                                             |
| **Пассивная иждивенка**             | Ушла, когда закончились ресурсы/комфорт, либо когда мужчина перестал "тащить" на себе её проблемы |
| **Гармоничная**                     | Разрыв по уважительной причине (бросил, бил, изменял). Не уходит по причине "любовь прошла"       |

#### Статистика отношений

_Варианты формулировок:_
- Сколько у тебя было мужчин? (Не уточняя "отношения" или "интим")

_Цель:_ Ловушка на скрытые связи

| Типаж                                                       | Индикатор в ответе                                            |
| ----------------------------------------------------------- | ------------------------------------------------------------- |
| **Властная соблазнительница** / **Импульсивная гедонистка** | Высокое число партнеров. Свободно говорит на эту тему         |
| **Дистанцирующаяся кокетка** / **Истероидная**              | Много "друзей" мужчин, но мало интима, или наоборот           |
| **Гармоничная**                                             | Небольшое число. **Более 3-4 отношений - риск непригодности** |

_Цель:_ Определить тип нервной системы

| Типаж                                              | Индикатор в ответе                  |

| **Импульсивная гедонистка** / **Агрессивный боец** | Экстрим. Спокойствие = скука/смерть |

_Цель:_ Выявить склонность к "качелям"

| Типаж                               | Индикатор в ответе                                       |
| ----------------------------------- | -------------------------------------------------------- |
| **Истероидная натура (Драма-квин)** | Да, были. "Любовь-ненависть"                             |
| **Агрессивный боец**                | Были, с бурными ссорами                                  |
| **Гармоничная**                     | Точка была поставлена сразу. Больные отношения отвергает |

#### Реакция на стресс

_Варианты формулировок:_
- Как часто возникали конфликты в отношениях?
- А как ты обычно ругаешься? Посуду бьешь, с кулаками набрасываешься? (Со смайликом или спрашивать "играючи")

_Цель:_ Определить способ выхода агрессии

| Типаж                   | Индикатор в ответе                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Агрессивный боец**    | "Кулаками машу", "Посуду била". Прямая агрессия                                                                                |
| **Истероидная натура**  | Истерики, крики, угрозы                                                                                                        |
| **Гиперконтролирующая** | Давление голосом, "железные" аргументы                                                                                         |
| **Пассивная иждивенка** | Пассивная агрессия, надувание губ, молчание, игра в "бедняжку" или манипуляция слезами/здоровьем ("голова болит", "мне плохо") |
| **Гармоничная**         | "Не ругаюсь, обсуждаю". Молчит, не агрессирует                                                                                 |

#### Способность к одиночеству

_Варианты формулировок:_
- Долго ли ты переживала разрыв отношений? Пробовала ли ты на кого-то переключиться?

_Цель:_ Выявить использование мужчин как "костыля"

| Типаж                                                | Индикатор в ответе                                                               |
| ---------------------------------------------------- | -------------------------------------------------------------------------------- |
| **Импульсивная гедонистка** / **Истероидная натура** | Сразу начала искать другого. Переключение - способ избежать боли                 |
| **Пассивная иждивенка**                              | Быстро нашла того, кто "позаботится"                                             |
| **Гармоничная**                                      | Переживала, занималась собой. Принцип: "Либо переключается всегда, либо никогда" |

### Моральные границы и Верность

#### Границы верности

_Варианты формулировок:_
- Как ты действовала в отношениях, когда возникала мимолетная симпатия к другому мужчине? (Подразумевая, что симпатии точно были)

_Цель:_ Проверка целостности

| Типаж                         | Индикатор в ответе                                     |
| ----------------------------- | ------------------------------------------------------ |
| **Импульсивная гедонистка**   | "Запрещала себе", "Подавляла". Или "ничего не делала"  |
| **Властная соблазнительница** | Признается в флирте, но с вызовом                      |
| **Гармоничная**               | "У меня такого не было". Не допускает мыслей об измене |

#### Отношение к сексу

- Были ли у тебя свободные отношения?

_Цель:_ Определить уровень морали, наличие потребительского/гедонистического отношения к сексу

| Типаж                                                                                   | Индикатор в ответе                             |
| --------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **Импульсивная гедонистка** / **Властная соблазнительница** / **Материальная тунеядка** | Были. Аргумент: "Маленькая была", "Было время" |
| **Гармоничная**                                                                         | Категорическое нет. Это табу                   |

#### Скрытые связи

_Варианты формулировок:_
- Сколько у тебя было мужчин в плане интима?

_Цель:_ Выявить разницу между заявленным количеством отношений и количеством партнеров 

| Типаж                                                   | Индикатор в ответе                                                       |
| ------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Импульсивная гедонистка** / **Материальная тунеядка** | Число интимных партнеров **больше** числа отношений. "Ну, бывало всякое" |
| **Властная соблазнительница**                           | Может быть большое число, но озвучивает это как достижения/завоевания    |
| **Гармоничная**                                         | Число партнеров совпадает с числом отношений                             |
