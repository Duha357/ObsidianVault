# Job

## Назначение
Личный плейбук поиска работы: резюме, поиск вакансий, собеседования.
Прикладные тактики «под рынок», а не теория.

## Структура
- `Assets/` — артефакты (резюме и т.п.).
- `Strategy/` — тактики: поиск вакансий, прохождение собеседований.

## Соглашения
- Формат заметок: разделы + подпункты, коллауты Obsidian
  (`> [!tip]`, `> [!danger]`) — сохранять и использовать при дополнении.
- Тон прагматичный, ориентированный на результат. Не морализировать.
- Правило автора: «Одно резюме = одна роль». Учитывать при работе с Assets.
- Факты, цифры, шаблоны фраз не выхолащивать при редактировании.
