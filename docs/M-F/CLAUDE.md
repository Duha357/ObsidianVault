# M-F

## Назначение
Личные материалы автора по стратегии отношений М/Ж:
типология, диагностика, тактики коммуникации.

## Характер
Личный, приватный контент. Авторская позиция и формулировки —
не смягчать, не морализировать, не редактировать по своим взглядам.
Работать строго по запросу автора.

## Структура
- `Типы.md`, `Вопросы определения типа.md` — типология и диагностика.
- `Досье.md`, `Анкета.md` — сбор данных.
- `Дистанцирование.md`, `Игнор.md` — тактики. `Грехи.md` — модель пороков.

## Соглашения
- Формат: разделы, таблицы «Типаж | Индикатор», списки «НУЖНО / НЕЛЬЗЯ».
  Сохранять структуру при дополнении.
- Терминологию автора (названия типов, тактик) не переименовывать.
