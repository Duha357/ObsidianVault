# Walkthrough — база знаний по играм

Здесь хранится информация по пройденным играм, чтобы можно было
вернуться к ней в любой момент.

## Организация
- Одна игра — одна папка (например, `Gothic 1 Remake/`).
- Внутри папки игры заметки разбиты по категориям и связаны между собой.
- Набор категорий у каждой игры свой (задания, персонажи, места,
  предметы, снаряжение, механики и т.п.) — не фиксирован и не обязателен.

## Связи
- Заметки одной игры ссылаются друг на друга через wikilinks без пути — `[[Название]]`.
- При работе с заметкой стоит читать связанные заметки той же игры:
  контекст часто лежит именно в них.
- Связи не выходят за пределы папки игры — разные игры не смешиваются.

## Соглашения
- Формат: Markdown, `.md`.
- Много таблиц и списков; оформление у каждой игры своё.
- Существующее оформление сохранять как есть, без переформатирования без просьбы.
