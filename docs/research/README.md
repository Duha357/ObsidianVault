# Исследования — индекс

Датированные разборы тем из проверенных источников. Сырьё, из которого
рождаются и обновляются плейбуки в доменах. Что это за слой — см. [[scope]].

## Правила

- **Один файл = одно исследование.** Именование: `ГГГГ-ММ-тема.md`
  (kebab-case), например `2026-07-english-methodika.md`.
- **Старое не перезаписываем.** Повторное исследование той же темы —
  это новый файл с новой датой. Оба лежат рядом, прошлое доступно для
  исторического сравнения.
- В таблице ниже отмечай, какой файл по теме **актуальный**, а какой —
  **исторический**.
- Формат наполнения задаёт research-скилл (в доработке); до него —
  свободная структура по [[conventions]].
