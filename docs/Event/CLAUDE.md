# Event

## Назначение
Шаблоны для организации IT-конференции (образец — Ural Digital Weekend).
Материалы переиспользуются между мероприятиями.

## Ключевой принцип: это шаблоны
- Даты-заглушки (01.01.2000, 01.01.2020 и т.п.) — намеренные плейсхолдеры.
  НЕ «исправлять» на реальные без явной просьбы.
- Числа аудитории, ссылки, названия секций — примерные, если не сказано иначе.

## Структура
- `Templates/ru/До/` — документы этапа «до мероприятия».
- `Instructions/` — инструкции спикерам. `CTA/` — призывы к действию.
- `JSON/` — машиночитаемые описания секций (не ломать синтаксис JSON).
- `Промпт.md` — заготовки ролей/промптов для генерации текстов.

## Соглашения
- Стиль текстов — деловой, структурированный по разделам «О ...».
- Внутренние ссылки — wikilinks без пути: `[[Навигация мероприятия]]`.
