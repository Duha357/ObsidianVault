## Явное

Понятное. Чаще встречающееся. Открытое. Логичное. Прямое. Откровенное

Пример:
- Fast‑track strategies
- Lifehacks
- Loss minimization tactics
- Optimizations
	- Time, Resources, Quality savers
- Pro tips
- Workarounds
- Shortcuts
- Hints
- Tricks
- Best practices
- Fast wins
- Creative uses

## Не явное

Не понятное. Редко встречающееся. Закрытое. Кажущееся логичным. Не логичное. Косвенное. Уклончивое

Пример:
- Loopholes
- Backdoor methods
- Insider tricks
- Bugs
- Undocumented features
- Unconventional approaches
- Non‑obvious opportunities
- Efficiency hacks
- Alternate routes

## Асоциальное

Не принятое обществом

Пример:
- Cheat codes
- Exploits
- Glitches
- Dark patterns
