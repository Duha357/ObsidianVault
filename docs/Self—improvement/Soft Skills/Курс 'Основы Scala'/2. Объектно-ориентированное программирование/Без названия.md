## Наследование и полиморфизм

## Механизмы наследования

Как и в большинстве языков, Scala поддерживает одиночное наследование классов. Класс-наследник получает возможность использовать все public и protected методы.

Для расширения класса используется ключевое слово extends. Этот код создаст базовый класс Media, и унаследует от него AudioBook.

class Media:

  def format(): String = "Unknown format"

class AudioBook extends Media:

  override def format(): String = "MP3 Audio" 

---

## Переопределение и ключевое слово override

В Scala использование override является обязательным при переопределении метода или поля родительского класса, в отличие от Java, где аннотацию @Override можно опустить.

Обязательность защищает от случайных неправильных переопределений.

override def format(): String = "MP3 Audio" 

---

## Вызов конструктора родителя и super

Если у родительского класса есть поля конструктора, то наследник должен передать поля прямо в момент наследования.

А если наследник хочет использовать базовую логику какого-то метода и добавить к ней свою логику, то обратиться к базовой он может через super

class Media(val title: String):

  def info(): String = s"Название: $title"

  

class AudioBook(title: String) extends Media(title):

  // Добавляем к базовому описанию тип файла

  override def info(): String = super.info() + " (Аудиокнига, MP3)"

  

class VideoCourse(title: String) extends Media(title):

  // Добавляем к базовому описанию параметры видео

  override def info(): String = super.info() + " (Видео, 1080p)" 

---

## Полиморфизм времени выполнения

Полиморфизм — это способность обрабатывать объекты разных типов так, как будто это общий тип.

Вызывается реализация метода, которая соответствует типу во время выполнения, а не во время компиляции.

Обычно полиморфизм ассоциируется с тем, что можно хранить разные ссылки на один и тот же объект. Поскольку мы стараемся не использовать изменяемые ссылки, то у нас другое преимущество - возможность складывать разные объекты в одну коллекцию или передавать их в одну функцию. 

Например, в примере ниже будет создан список из Media, в которые мы можем класть как аудио, так и видеокниги. Для каждого элемента списка вызовется правильная версия вызова info() в зависимости от того, аудиокнига это или видеокнига.

class Media(val title: String):

  def info(): String = s"Название: $title"

  

class AudioBook(title: String) extends Media(title):

  override def info(): String = super.info() + " (Аудиокнига, MP3)"

  

class VideoCourse(title: String) extends Media(title):

  override def info(): String = super.info() + " (Видео, 1080p)"

  

val libraryCatalog: List[Media] = List(

  new AudioBook("Дюна"),

  new VideoCourse("Коллекции в Scala")

)

  

libraryCatalog.foreach(item => println(item.info()))

// Вывод

// Название: Дюна (Аудиокнига, MP3)

// Название: Коллекции в Scala (Видео, 1080p)

## Использование final

Ключевое слово final применяется, чтобы запретить программистам расширять код. Это нужно, чтобы гарантировать, что код во всех местах использования будет одинаково и предсказуемо себя вести.

Добавление val не только делает код безопаснее, но и убыстряет программу. Компилятор видит, что объект final, и применяет к нему оптимизации

Для класса final означает, что никто не сможет от него отнаследоваться. 

final class ISBNValidator 

Для метода final означает, что его класс (если он есть) останется открытым для наследования, но метод нельзя будет переопределить.

class Media(val id: String):

  final def generateBarcode(): String = 

    s"BARCODE-$id" 

Val тоже можно переопределять! Поэтому для переменной final означает, что её нельзя переопределить.

final val publisher = "Эксмо"**
