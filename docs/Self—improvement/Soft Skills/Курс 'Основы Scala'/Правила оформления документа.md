## Код

- Примеры Scala — блоки ```scala.
- Перед примером Scala — описание, что делает код и что хотим показать т.е. ожидаемый результат (понять из контекста примера и текста блока документа). Отдельными абзацами.
- Если в блоке есть ссылка на пример Scala — поместить к самому примеру в блок ```scala.
- Описание примера Scala и текста блока схожи — переформулировать оба текста. Пример — ожидаемый результат с учётом контекста текста, текст — общие случаи.
- Текст описания примера должно быть понятно, почему этот пример приведён.
- Ошибки в коде не чинить — намеренные.
- Дублирование — игнорировать.
- Пример + предложение-описание — в сворачиваемый callout `> [!example]- Заголовок`.
- Шаблон примера: `Пример: {про что пример в именительном падеже}`
- Внутри callout: описание, код-блок, .
- **Не:**
	- Писать в ожидаемый результат описания примера Scala, просто вставку кода.
