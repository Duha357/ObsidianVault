## Списки

- Между пунктами нет пустых строк.
- Нет лишних пробелов в начале строк.

## Код

- Примеры Scala — блоки ```scala.
- Перед примером Scala — описание ожидаемого результата (понять из контекста примера и текста блока документа).
- Если в блоке есть ссылка на пример Scala — поместить к самому примеру в блок ```scala.
- Описание примера Scala и текста блока схожи — переформулировать оба текста. Пример — ожидаемый результат, текст — общие случаи.
- Ошибки в коде не чинить — намеренные.
- Дублирование — игнорировать.
- Пример + предложение-описание — в сворачиваемый callout `> [!example]- Заголовок`.
- Внутри callout: описание, затем код-блок.

## Текст

- Исправляй опечатки и грамматику.
- Удаляй хвостовой `**` в конце файла.
