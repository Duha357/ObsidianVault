## Выражения, инструкции и блоки кода в Scala

Выражение вычисляется и возвращает значение. Инструкция выполняет действие, значения не возвращает. Scala построена вокруг выраженческой модели: программы — композиции выражений.

---

## Expression vs Statement

Инструкция выполняет действие. Выражение вычисляется и возвращает значение.

##### Инструкция (statement)

Инструкция выполняет действие, значения не возвращает. Используется ради побочного эффекта.

> [!example]- Пример: if как инструкция
> Код использует `if` для вывода сообщения при условии.
>
> При `bookCount > 0` выводится `Books available`; `if` значения не возвращает.
>
> ```java
> if (bookCount > 0) {
>     System.out.println("Books available");
> }
> ```
>
> Пример показывает: в императивных языках `if` — инструкция.

##### Выражение (expression)

Выражение вычисляется и всегда возвращает значение. Может быть частью более крупного выражения.

---

## Почти всё — выражение

В Scala почти всё — выражение: арифметика, `if`, `match`, блоки кода.

##### Арифметические операции

Арифметическая операция — выражение: вычисляется и возвращает значение.

> [!example]- Пример: арифметическое выражение
> Код объявляет `totalBooks` результатом сложения.
>
> `15 + 25` — выражение типа Int; `totalBooks` — 40.
>
> ```scala
> val totalBooks = 15 + 25
> ```
>
> Пример показывает: арифметика возвращает значение.

##### Условные конструкции

`if` в Scala — выражение: возвращает значение, тип определяется ветками. При разных типах веток компилятор выводит общий супертип.

> [!example]- Пример: if как выражение
> Код присваивает результат `if` значению `libraryStatus`.
>
> При `bookCount > 0` — `"open"`, иначе — `"empty"`.
>
> ```scala
> val libraryStatus =
>   if bookCount > 0 then "open"
>   else "empty"
> ```
>
> Пример показывает: `if` возвращает значение.

##### Match-выражения

`match` — выражение: возвращает значение, тип определяется ветками.

> [!example]- Пример: match как выражение
> Код сопоставляет `bookCount` с образцами.
>
> При `bookCount = 0` — `"no books"`, иначе — `"books: N"`.
>
> ```scala
> val bookCategory = bookCount match
>   case 0 => "no books"
>   case n => s"books: $n"
> ```
>
> Пример показывает: `match` возвращает значение.

##### Блок как выражение

Блок `{ ... }` объединяет выражения, возвращает значение последнего, имеет собственную область видимости.

> [!example]- Пример: блок как выражение
> Код объявляет `availableBooks` блоком с локальными значениями и суммой.
>
> `availableBooks` — 30: значение последнего выражения.
>
> ```scala
> val availableBooks = {
>   val fictionBooks = 10
>   val scienceBooks = 20
>   fictionBooks + scienceBooks
> }
> ```
>
> Пример показывает: блок — полноценное выражение.

---

## Отсутствие необходимости в return

Метод возвращает значение последнего выражения. `return` не требуется и не идиоматичен.

Использование `return`:

- Нарушает функциональный стиль.
- Вводит императивную семантику преждевременного выхода.
- Редко применяется в реальном Scala-коде.

> [!example]- Пример: неявный возврат
> Код объявляет `doubleBook` без `return`.
>
> `doubleBook(5)` возвращает 10 — значение последнего выражения.
>
> ```scala
> def doubleBook(count: Int): Int =
>   count * 2
> ```
>
> Пример показывает: `return` не требуется.

> [!example]- Пример: return
> Код объявляет `doubleBook` с `return`.
>
> `doubleBook(5)` возвращает 10; `return` работает, но не идиоматичен.
>
> ```scala
> def doubleBook(count: Int): Int =
>   return count * 2
> ```
>
> Пример показывает: `return` избыточен.

## Побочные эффекты и тип Unit

Выражение ради эффекта возвращает тип Unit. Unit — аналог void, но полноценный тип с единственным значением `()`.

> [!example]- Пример: тип Unit
> Код присваивает результат `println`.
>
> `result` — Unit: `println` выполнил эффект, значения не нёс.
>
> ```scala
> val result = println("New book added")
> ```
>
> Пример показывает: Unit — тип выражений с побочным эффектом.

---

## Точка с запятой

Точка с запятой необязательна: компилятор разделяет выражения по переводу строки. Требуется при нескольких выражениях на одной строке. Идиоматический стиль — одна инструкция на строку без `;`.

> [!example]- Пример: без точки с запятой
> Код объявляет два значения на разных строках.
>
> `authorName` — `"Tolkien"`, `bookTitle` — `"The Hobbit"`; разделитель не нужен.
>
> ```scala
> val authorName = "Tolkien"
> val bookTitle = "The Hobbit"
> ```
>
> Пример показывает: перевод строки разделяет выражения.

> [!example]- Пример: точка с запятой
> Код объявляет два значения на одной строке.
>
> Оба значения объявлены; разделитель — `;`.
>
> ```scala
> val authorName = "Rowling"; val bookTitle = "Harry Potter"
> ```
>
> Пример показывает: `;` нужна при нескольких выражениях на строке.

## Практическое сравнение с Java

Scala приближает синтаксис к функциональной модели: программы — композиции выражений.

| Концепция | Java | Scala |
|---|---|---|
| if | инструкция | выражение |
| switch | инструкция | match-выражение |
| блок | группа инструкций | выражение |
| return | обязателен | не требуется |
| void | не тип | Unit — тип |
