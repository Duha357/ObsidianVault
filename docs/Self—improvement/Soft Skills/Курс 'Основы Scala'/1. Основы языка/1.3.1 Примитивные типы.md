# Типы данных в Scala

## Общая модель типов в Scala

Scala — строго типизированный язык с единой иерархией типов.

Корневой тип — Any, который делится на:

- AnyVal — примитивные (значимые) типы;
- AnyRef — ссылочные типы (объекты).

Примитивные типы в Scala логически являются объектами (имеют методы), но компилируются в JVM-примитивы для эффективности.

Это важное отличие от Java, где примитивы и объекты существуют как две концептуально разные категории.

## Целочисленные типы

| Тип | Размер | Диапазон |
|---|---|---|
| Byte | 8 бит | -128 .. 127 |
| Short | 16 бит | -32 768 .. 32 767 |
| Int | 32 бит | ~ -2^31 .. 2^31-1 |
| Long | 64 бит | ~ -2^63 .. 2^63-1 |

### Int — основной числовой тип

Целочисленные литералы по умолчанию имеют тип Int. Для Long требуется суффикс L.

> [!example]- Пример: литералы Int и Long
> Литерал без суффикса получает тип Int.
> Литерал с суффиксом L получает тип Long.
>
> Ожидаемый результат: `bookCount` — Int, `totalPages` — Long.
>
> ```scala
> val bookCount = 42        // Int
> val totalPages = 5000L    // Long
> ```
>
> Пример показывает: как задать целочисленные литералы Int и Long.

### Арифметические операции

Арифметические операции выполняются над целыми числами. Тип результата определяется правилами числового продвижения.

> [!example]- Пример: сложение и умножение
> Сложение и умножение целочисленных литералов.
>
> Ожидаемый результат: `borrowedBooks` = 15, `shelfCapacity` = 100.
>
> ```scala
> val borrowedBooks = 10 + 5
> val shelfCapacity = 4 * 25
> ```
>
> Пример показывает: как выполнять арифметические операции над целыми числами.

## Типы с плавающей точкой

| Тип | Размер | Стандарт |
|---|---|---|
| Float | 32 бит | IEEE 754 |
| Double | 64 бит | IEEE 754 |

Литералы с плавающей точкой по умолчанию имеют тип Double. Для Float используется суффикс f.

> [!example]- Пример: литералы Double и Float
> Литерал без суффикса получает тип Double.
> Литерал с суффиксом f получает тип Float.
>
> Ожидаемый результат: `averageRating` — Double, `bookWeight` — Float.
>
> ```scala
> val averageRating = 4.8   // Double
> val bookWeight = 1.5f     // Float
> ```
>
> Пример показывает: как задать литералы Double и Float.

Double предпочтителен в большинстве случаев из-за большей точности.

## Символьный тип Char

Char — 16-битный Unicode-символ. Внутренне соответствует UTF-16 представлению JVM.

> [!example]- Пример: объявление Char
> Объявление переменной символьного типа.
>
> Ожидаемый результат: `firstLetter` содержит символ `'A'`.
>
> ```scala
> val firstLetter: Char = 'A'
> ```
>
> Пример показывает: как объявить символьный литерал.

Char может участвовать в арифметических операциях как числовой код символа.

> [!example]- Пример: числовой код символа
> Преобразование символа в числовой код.
>
> Ожидаемый результат: `letterCode` равен 65.
>
> ```scala
> val letterCode = 'A'.toInt
> ```
>
> Пример показывает: как получить числовой код символа.

## Логический тип Boolean

Boolean принимает только два значения: true и false. Используется в условных выражениях.

> [!example]- Пример: сравнение
> Сравнение количества доступных книг с нулём.
>
> Ожидаемый результат: `isAvailable` равен true при `availableBooks > 0`.
>
> ```scala
> val isAvailable = availableBooks > 0
> ```
>
> Пример показывает: как вычислить булево значение сравнением.

## Примитивные vs непримитивные типы

Примитивные типы в Scala имеют две модели представления: логическую и физическую.

### Логическая модель

В Scala всё является объектом. Int — подтип AnyVal, поэтому у его значений есть методы.

> [!example]- Пример: метод toString у Int
> Вызов метода `toString` у целочисленного значения.
>
> Ожидаемый результат: строка `"10"`.
>
> ```scala
> val bookCount = 10
> bookCount.toString
> ```
>
> Пример показывает: что у примитивных значений есть методы, как у объектов.

### Физическая модель (JVM)

На уровне JVM:

- Int, Long, Double и др. компилируются в примитивные типы JVM;
- при необходимости автоматически упаковываются (boxing) в объекты (java.lang.Integer и т.д.);
- при возврате к примитивной форме происходит распаковка (unboxing).

При помещении примитивов в коллекции происходит автоупаковка.

> [!example]- Пример: автоупаковка в списке
> Создание списка целых чисел.
>
> Ожидаемый результат: элементы списка — упакованные объекты.
>
> ```scala
> val bookIds = List(101, 102, 103)
> ```
>
> Пример показывает: как примитивы упаковываются в объекты в коллекциях.

### Отличия от непримитивных типов

| Характеристика | Примитивы (AnyVal) | Ссылочные типы (AnyRef) |
|---|---|---|
| Хранение | Значение | Ссылка на объект |
| null | Не допускается | Допускается (в JVM) |
| Производительность | Высокая | Ниже (из-за аллокаций) |
| Наследование | Нет пользовательского | Полноценное ООП |

Примитивные типы:

- не могут наследоваться пользователем;
- не имеют изменяемого состояния;
- оптимизированы для производительности.

## Тип String

String в Scala — это java.lang.String.

> [!example]- Пример: объявление строки
> Объявление переменной строкового типа.
>
> Ожидаемый результат: `authorName` содержит строку `"George Orwell"`.
>
> ```scala
> val authorName: String = "George Orwell"
> ```
>
> Пример показывает: как объявить строковую переменную.

Особенности:

- неизменяемый тип;
- ссылочный (подтип AnyRef);
- богатый API;
- интеграция с Java без преобразований.

### Интерполяция строк

Scala предоставляет встроенную интерполяцию строк. Значение переменной подставляется через `$`.

> [!example]- Пример: интерполяция s
> Подстановка значения `bookCount` в строку.
>
> Ожидаемый результат: `message` содержит `"Books in library: 30"`.
>
> ```scala
> val bookCount = 30
> val message = s"Books in library: $bookCount"
> ```
>
> Пример показывает: как встроить значение переменной в строку.

Другие формы интерполяции:

- `f"..."` — форматированная строка;
- `raw"..."` — без экранирования.

---

## Null и Nothing

- Null — подтип всех AnyRef.
- Nothing — подтип всех типов (используется для выражений, которые никогда не возвращают значение).

В идиоматическом Scala рекомендуется избегать null в пользу Option.

---

## Иерархия типов

Any — корень иерархии. AnyVal — примитивы, AnyRef — ссылочные типы. Null — подтип всех AnyRef, Nothing — подтип всех типов.
