# Типы данных в Scala

## Примитивные типы

---

## Общая модель типов в Scala

Scala — строго типизированный язык с единой иерархией типов.

Корневой тип — Any, который делится на:

- AnyVal — примитивные (значимые) типы;
    
- AnyRef — ссылочные типы (объекты).
    

Примитивные типы в Scala логически являются объектами (имеют методы), но компилируются в JVM-примитивы для эффективности.

Это важное отличие от Java, где примитивы и объекты существуют как две концептуально разные категории.

---

## Целочисленные типы

  

|   |   |   |
|---|---|---|
|Тип|Размер|Диапазон|
|Byte|8 бит|-128 .. 127|
|Short|16 бит|-32 768 .. 32 767|
|Int|32 бит|~ -2^31 .. 2^31-1|
|Long|64 бит|~ -2^63 .. 2^63-1|

### Int — основной числовой тип

По умолчанию целочисленные литералы имеют тип Int:

val bookCount = 42        // Int

Для Long требуется суффикс L:

val totalPages = 5000L       // Long

### Арифметические операции

val borrowedBooks = 10 + 5  
val shelfCapacity = 4 * 25

Результат имеет тип, определяемый правилами числового продвижения.

---

## Типы с плавающей точкой

  

|   |   |   |
|---|---|---|
|Тип|Размер|Стандарт|
|Float|32 бит|IEEE 754|
|Double|64 бит|IEEE 754|

По умолчанию литералы с плавающей точкой имеют тип Double:

val averageRating = 4.8      // Double

Для Float используется суффикс f:

val bookWeight = 1.5f     // Float

Double предпочтителен в большинстве случаев из-за большей точности.

---

## Символьный тип Char

Char — 16-битный Unicode-символ.

val firstLetter: Char = 'A'

Внутренне соответствует UTF-16 представлению JVM.

Char может участвовать в арифметических операциях (как числовой код символа):

val letterCode = 'A'.toInt

---

## Логический тип Boolean

Boolean принимает только два значения:

true  
false

Используется в условных выражениях:

val isAvailable = availableBooks > 0

---

## Примитивные vs непримитивные типы

### Логическая модель

В Scala всё является объектом:

val bookCount = 10  
bookCount.toString

Метод toString вызывается у Int.

Это возможно потому, что Int является подтипом AnyVal.

---

### Физическая модель (JVM)

На уровне JVM:

- Int, Long, Double и др. компилируются в примитивные типы JVM;
    
- при необходимости они автоматически упаковываются (boxing) в объекты (java.lang.Integer и т.д.);
    
- при возврате к примитивной форме происходит распаковка (unboxing).
    

Пример автоупаковки:

val bookIds = List(101, 102, 103)

Здесь элементы списка представлены как объекты.

---

### Отличия от непримитивных типов

  

|   |   |   |
|---|---|---|
|Характеристика|Примитивы (AnyVal)|Ссылочные типы (AnyRef)|
|Хранение|Значение|Ссылка на объект|
|null|Не допускается|Допускается (в JVM)|
|Производительность|Высокая|Ниже (из-за аллокаций)|
|Наследование|Нет пользовательского|Полноценное ООП|

Примитивные типы:

- не могут наследоваться пользователем;
    
- не имеют изменяемого состояния;
    
- оптимизированы для производительности.
    

---

## Тип String

String в Scala — это java.lang.String.

val authorName: String = "George Orwell"

Особенности:

- неизменяемый тип;
    
- ссылочный (подтип AnyRef);
    
- богатый API;
    
- интеграция с Java без преобразований.
    

### Интерполяция строк

Scala предоставляет встроенную интерполяцию:

val bookCount = 30  
val message = s"Books in library: $bookCount"

Другие формы:

- f"..." — форматированная строка;
    
- raw"..." — без экранирования.
    

---

## Null и Nothing

Для полноты картины:

- Null — подтип всех AnyRef;
    
- Nothing — подтип всех типов (используется для выражений, которые никогда не возвращают значение).
    

Однако в идиоматическом Scala рекомендуется избегать null в пользу Option.
