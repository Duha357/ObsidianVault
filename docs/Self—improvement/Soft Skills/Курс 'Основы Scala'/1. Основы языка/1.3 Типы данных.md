# Типы данных

Scala — язык со строго-статической типизацией, поэтому типы данных играют центральную роль. Они:

- Обеспечивают безопасность программ.
- Выражают намерения разработчика.
- Позволяют компилятору обнаруживать ошибки до запуска.
- Участвуют в проектировании архитектуры системы.

---

## Примитивные и непримитивные типы

На уровне JVM существуют примитивные типы (int, double, boolean и др.) и ссылочные типы (объекты). Scala сохраняет эффективность примитивов, но на уровне языка следует принципу: в Scala всё выглядит как объект.

> [!example]- Пример: вызов метода у Int
> 
> Объявляет значение x типа Int и вызывает у него метод toString.
> 
> Ожидаемый результат: x.toString возвращает строку "10".
> 
> ```scala
> val x = 10
> x.toString
> ```
> 
> Пример показывает: на уровне языка Int ведёт себя как объект, хотя компилируется в JVM-примитив int.

Хотя Int компилируется в JVM-примитив int, с точки зрения языка он ведёт себя как полноценный объект с методами. При необходимости компилятор выполняет автоматическую упаковку и распаковку (boxing/unboxing). Это обеспечивает:

- Единообразную объектную модель.
- Совместимость с JVM.
- Высокую производительность.

## Числовые типы

##### Целочисленные типы

| Тип | Размер | Пример |
| --- | --- | --- |
| Byte | 8 бит | `val b: Byte = 10` |
| Short | 16 бит | `val s: Short = 300` |
| Int | 32 бита | `val i: Int = 42` |
| Long | 64 бита | `val l: Long = 1_000_000L` |

Особенности:

- Int — тип по умолчанию для целых чисел.
- Для Long используется суффикс L.

##### Типы с плавающей точкой

| Тип | Размер | Назначение |
| --- | --- | --- |
| Float | 32 бита | экономия памяти |
| Double | 64 бита | стандартная точность |

> [!example]- Пример: объявление Double и Float
> 
> Объявляет pi типа Double и f типа Float.
> 
> Ожидаемый результат: переменные получают значения с плавающей точкой.
> 
> ```scala
> val pi: Double = 3.1415
> val f: Float = 2.5f
> ```
> 
> Пример показывает: для Float литерал записывается с суффиксом f.

По умолчанию литералы с плавающей точкой имеют тип Double.

## Символьный и логический типы

> [!example]- Пример: объявление Char и Boolean
> 
> Объявляет символьную переменную c и логическую isReady.
> 
> Ожидаемый результат: c содержит 'A', isReady — true.
> 
> ```scala
> val c: Char = 'A'
> val isReady: Boolean = true
> ```
> 
> Пример показывает: синтаксис объявления Char и Boolean.

- Char представляет один символ Unicode.
- Boolean принимает значения true или false.

##### Логические операции: «И» и «ИЛИ»

В Scala используются логические операторы:

- && — логическое «И» (and).
- || — логическое «ИЛИ» (or).
- ! — логическое отрицание.

> [!example]- Пример: логические операторы и короткое замыкание
> 
> Вычисляет условия через && и ||.
> 
> Ожидаемый результат: isAdult true при age от 18 до 64, isWeekend true для "Sat" и "Sun", expensiveOperation не вызывается.
> 
> ```scala
> val isAdult = age >= 18 && age < 65
> val isWeekend = day == "Sat" || day == "Sun"
> 
> false && expensiveOperation() // expensiveOperation не будет вызвана
> true  || expensiveOperation() // expensiveOperation не будет вызвана
> ```
> 
> Пример показывает: применение операторов к конкретным условиям и эффект короткого замыкания.

Операторы && и || обладают коротким замыканием (short-circuit evaluation): при false слева от && и true слева от || правая часть не вычисляется. Это важно при работе с условиями и потенциально дорогими вычислениями.

## Тип Unit

##### Назначение

Unit — аналог void в других языках, но реализованный как полноценный тип.

> [!example]- Пример: функция, возвращающая Unit
> 
> Объявляет функцию log, которая печатает сообщение.
> 
> Ожидаемый результат: вызов log("hi") печатает hi и возвращает ().
> 
> ```scala
> def log(msg: String): Unit =
>   println(msg)
> ```
> 
> Пример показывает: синтаксис функции, которая ничего не возвращает.

##### Единственное значение

Тип Unit имеет одно значение — ().

> [!example]- Пример: значение ()
> 
> Присваивает переменной u единственное значение типа Unit.
> 
> Ожидаемый результат: u содержит ().
> 
> ```scala
> val u: Unit = ()
> ```
> 
> Пример показывает: переменной типа Unit присваивается только значение ().

Так как Unit — обычный тип, он вписывается в выраженческую модель Scala.

## Типы-произведения (Product Types)

##### Концепция: логическое «И»

Тип-произведение означает, что значение содержит все компоненты одновременно. Пример логического «И»: пользователь имеет имя и возраст.

##### Кортежи (Tuples)

> [!example]- Пример: кортеж, доступ к элементам и распаковка
> 
> Создаёт кортеж из строки и числа, обращается к элементам через _1 и _2, распаковывает через деструктуризацию.
> 
> Ожидаемый результат: user._1 возвращает "Alice", user._2 — 30, name и age получают значения кортежа.
> 
> ```scala
> val user: (String, Int) = ("Alice", 30)
> 
> user._1
> user._2
> 
> val (name, age) = user
> ```
> 
> Пример показывает: создание кортежа Tuple2[String, Int], доступ к элементам и распаковку в Scala 3.

Тип кортежа из двух элементов — Tuple2[String, Int]. Кортежи используются для группировки данных без создания отдельного класса.

##### Case-классы — именованные типы-произведения

> [!example]- Пример: объявление case-класса
> 
> Объявляет case-класс User с полями name и age.
> 
> Ожидаемый результат: User("Alice", 30) создаётся без new и получает equals, hashCode, toString.
> 
> ```scala
> case class User(name: String, age: Int)
> ```
> 
> Пример показывает: синтаксис case-класса.

Особенности:

- Неизменяемость по умолчанию.
- Создание без new.
- Автоматически генерируются equals, hashCode, toString.
- Поддержка match.

Case-классы предпочтительнее кортежей в доменной модели.

## Типы-суммы (Sum Types)

##### Концепция: логическое «ИЛИ»

Тип-сумма означает, что значение может быть одним из нескольких вариантов, но только одним одновременно. Пример логического «ИЛИ»: фигура — это круг или прямоугольник.

##### sealed trait и исчерпывающий match

> [!example]- Пример: типы-суммы и исчерпывающий match
> 
> Объявляет sealed trait Shape с двумя case-классами и вычисляет площадь через match.
> 
> Ожидаемый результат: area(Circle(1)) возвращает π, area(Rectangle(2, 3)) — 6.
> 
> ```scala
> sealed trait Shape
> case class Circle(r: Double) extends Shape
> case class Rectangle(w: Double, h: Double) extends Shape
> 
> def area(s: Shape): Double =
>   s match
>     case Circle(r)        => math.Pi * r * r
>     case Rectangle(w, h)  => w * h
> ```
> 
> Пример показывает: перечисление вариантов через sealed trait и полноту match.

sealed означает, что все подтипы известны компилятору. Компилятор проверяет полноту сопоставления.

## Either — представление результата с ошибкой

> [!example]- Пример: Either для результата с ошибкой
> 
> Объявляет parseInt, которая преобразует строку в число.
> 
> Ожидаемый результат: parseInt("123") возвращает Right(123), parseInt("abc") — Left("Not a number").
> 
> ```scala
> def parseInt(s: String): Either[String, Int] =
>   if s.forall(_.isDigit) then Right(s.toInt)
>   else Left("Not a number")
> ```
> 
> Пример показывает: моделирование успеха и ошибки через Right и Left.

- Right — успешный результат.
- Left — ошибка.

Это тип-сумма: результат — число или сообщение об ошибке.

## Option и отсутствие значения

##### Проблема null

null является источником множества runtime-ошибок. В Scala предпочтительно явное моделирование отсутствия значения.

##### Тип Option

Option[+A] может быть Some(value) или None.

> [!example]- Пример: Some и None
> 
> Создаёт Option со значением и пустой Option.
> 
> Ожидаемый результат: name содержит Some("Scala"), empty — None.
> 
> ```scala
> val name: Option[String] = Some("Scala")
> val empty: Option[String] = None
> ```
> 
> Пример показывает: создание заполненного и пустого Option.

##### Почему Option лучше null

> [!example]- Пример: функция, возвращающая Option
> 
> Объявляет findUser, которая ищет пользователя по id.
> 
> Ожидаемый результат: findUser(1) возвращает Some("Alice"), findUser(2) — None.
> 
> ```scala
> def findUser(id: Int): Option[String] =
>   if id == 1 then Some("Alice") else None
> ```
> 
> Пример показывает: при отсутствии пользователя функция возвращает None, а не null.

Сигнатура функции явно сообщает вызывающему коду о возможном отсутствии значения.

##### Основные методы Option

Option предоставляет методы для преобразования значения и извлечения результата по умолчанию.

> [!example]- Пример: основные методы Option
> 
> Применяет к Option методы map, flatMap, getOrElse, orElse, fold.
> 
> Ожидаемый результат: каждый метод возвращает преобразованное значение или запасное.
> 
> ```scala
> val opt: Option[String] = Some("Scala")
> 
> opt.map(_.length)
> opt.flatMap(s => Some(s.toUpperCase))
> opt.getOrElse("Unknown")
> opt.orElse(Some("Default"))
> opt.fold(0)(_.length)
> ```
> 
> Пример показывает: базовые методы работы с Option.

## Идиоматический стиль Scala

> [!example]- Пример: императивный и функциональный стиль
> 
> Сравнивает обработку null в двух стилях.
> 
> Ожидаемый результат: оба выражения возвращают длину строки или 0, если x — null.
> 
> ```scala
> if x != null then x.length else 0
> 
> Option(x).map(_.length).getOrElse(0)
> ```
> 
> Пример показывает: функциональный стиль заменяет ручную проверку null композицией Option.

Scala поощряет:

- Композицию выражений.
- Явное моделирование состояний через типы.
- Отказ от ручных проверок null.
- Использование типов-сумм и типов-произведений для описания домена.
