## Общий обзор языка

Scala — статически типизированный язык общего назначения, сочетает объектно-ориентированную (ООП) и функциональную (ФП) парадигмы.

Scalable («масштабируемый») — основная идея: один язык и стиль программирования подходят и для небольших утилит, и для крупных распределённых и корпоративных систем.

ООП и ФП интегрированы на уровне базовых конструкций, не противопоставлены.

---

## Краткая история языка

Создан Мартином Одерски (Martin Odersky) и его командой. Вышел в 2004 году. Scala 2 — в 2006, Scala 3 — в 2021. Одерски участвовал в разработке дженериков Java — повлияло на архитектуру языка и совместимость с JVM.

Scala 3 — развитие Scala 2, не отдельный язык: приоритет обратной совместимости и миграции существующего кода.

---

## Scala 3 и преемственность от Scala 2

Scala 3 сохраняет фундаментальные идеи Scala 2:

- Классы и объекты.
- Трейты как средство композиции поведения.
- Сопоставление с образцом (pattern matching).
- Функции как значения и функциональные абстракции.
- Богатую стандартную библиотеку и коллекции.

Scala 3 перерабатывает и упрощает сложные механизмы Scala 2:

- Систему implicits (заменена на более явные и структурированные механизмы given / using).
- Синтаксис (уменьшение количества скобок и ключевых слов).
- Сообщения об ошибках компилятора и диагностику.

Для миграции есть автоматизированные инструменты, например sbt-scala3-migrate.

## Ключевые характеристики языка

##### Интеграция с Java и JVM

Совместимость с Java:

- Код Scala компилируется в байткод JVM.
- Классы Scala используют Java-библиотеки.
- Scala-классы наследуются от Java-классов и реализуют Java-интерфейсы.
- Возможно поэтапное внедрение Scala в Java-проекты.

##### Функции как значения первого класса

Функции можно:

- Присваивать переменным.
- Передавать в качестве аргументов.
- Возвращать из других функций.
- Хранить в структурах данных.

> [!example]- Пример: функции как значения
> `totalPages` — функция, присвоенная переменной. Вызывается как обычное значение.
>
> `totalPages(320, 210)` возвращает 500.
>
> ```scala
> val totalPages: (Int, Int) => Int = (firstBookPages, secondBookPages) => firstBookPages + secondBookPages
> println(totalPages(320, 210)) // 500
> ```
>
> Пример показывает: функция — значение первого класса.

##### Функции высшего порядка

Принимают другие функции параметрами или возвращают их результатом.

> [!example]- Пример: функции высшего порядка
> `applyTwice` принимает функцию `transform` параметром и применяет её дважды.
>
> `applyTwice(200, addBonus)` возвращает 300: каждое применение `addBonus` добавляет 50 страниц.
>
> ```scala
> def applyTwice(pages: Int, transform: Int => Int): Int =
>   transform(transform(pages))
>
> val addBonus = (pages: Int) => pages + 50 // каждое переиздание добавляет 50 страниц
> println(applyTwice(200, addBonus)) // 300
> ```
>
> Пример показывает: функция передана как аргумент.

##### Объекты как значения

Объекты — пространства имён, контейнеры утилитных функций, точки входа программы. Как и функции, являются значениями.

> [!example]- Пример: объект-синглтон
> `LibraryCatalog` — объект-синглтон с методом `isLongRead`. Метод передан в `filter` как значение.
>
> `longReads` — `List(520, 670)`: отфильтрованы книги больше 400 страниц.
>
> ```scala
> object LibraryCatalog:
>   def isLongRead(pages: Int): Boolean = pages > 400
>
> val books = List(150, 520, 380, 670)
> val longReads = books.filter(LibraryCatalog.isLongRead)
> println(longReads) // List(520, 670)
> ```
>
> Пример показывает: объект используется как значение и контейнер функций.

##### Строго статическая типизация и вывод типов

Типы проверяются на этапе компиляции. Автовывод типов сокращает количество явных аннотаций.

> [!example]- Пример: вывод типов без аннотаций
> Тип вычисляется по значению, аннотация не нужна.
>
> `pageCount` — Int, `title` — String.
>
> ```scala
> val pageCount = 320 // Int
> val title = "Dune" // String
> ```
>
> Пример показывает: автовывод типов работает на литералах.

> [!example]- Пример: вывод возвращаемого типа
> Тип результата вычисляется по телу функции, аннотация не нужна.
>
> Тип `formatBookEntry` выводится как `(String, String) => String`.
>
> ```scala
> def formatBookEntry(name: String, author: String) = s"$title by $author"
> ```
>
> Пример показывает: автовывод работает и для функций.

> [!example]- Пример: ошибка несовместимости типов
> Литерал `"three hundred"` несовместим с аннотацией `Int`.
>
> Строка `val pageCount: Int = "three hundred"` — ошибка компиляции до запуска.
>
> ```scala
> val pageCount: Int = "three hundred" // ошибка компиляции
> ```
>
> Пример показывает: статическая проверка типов на этапе компиляции.

## Философия языка

##### Снижение синтаксического шума

Scala 3 стремится к читаемому и предсказуемому синтаксису, особенно в управляющих конструкциях.

> [!example]- Пример: синтаксис Scala 2 и Scala 3
> Один и тот же метод на двух версиях синтаксиса.
>
> Обе версии эквивалентны: `newerEdition(2019, 2020)` возвращает 2020.
>
> Scala 2:
>
> ```scala
> def newerEdition(firstYear: Int, secondYear: Int): Int = {
>   if (firstYear > secondYear) firstYear else secondYear
> }
> ```
>
> Scala 3:
>
> ```scala
> def newerEdition(firstYear: Int, secondYear: Int): Int =
>   if firstYear > secondYear then firstYear else secondYear
> ```
>
> Пример показывает: Scala 3 убирает скобки и служебные слова.

Отсутствие фигурных скобок и минимизация служебных слов приближают код к декларативному описанию логики.

##### Минимизация шаблонного кода

Высокоуровневые конструкции устраняют повторяющийся код.

При создании классов: в Java ручной код — конструкторы, геттеры, equals; в Scala — одна строка.

При создании объектов: `new` не требуется.

> [!example]- Пример: создание экземпляра case class
> `case class` генерирует конструктор, `equals`, `hashCode`, `toString`, `copy` автоматически.
>
> `Book(...)` создаёт экземпляр без `new`; `println(book)` выводит `Book(The Master and Margarita, Bulgakov, 1967, 480)`.
>
> ```scala
> case class Book(name: String, author: String, year: Int, pages: Int)
>
> val book = Book("The Master and Margarita", "Bulgakov", 1967, 480)
> println(book)
> ```
>
> Пример показывает: шаблонный код сведён к одной строке.

`case class` автоматически генерирует:

- Equals и hashCode.
- ToString.
- Метод copy.
- Поддержку сопоставления с другим экземпляром (образцом).

##### Сопоставление с образцом (Pattern Matching)

Сравнивает не только значения, но и структуру объекта — в других языках это дорогая операция.

Выигрыш заметнее на объектах и коллекциях, чем на строках и числах.

> [!example]- Пример: сопоставление с образцом
> `describeCatalogItem` разбирает значение по типу и структуре.
>
> Для `Book("Dune", "Herbert", 1965, 412)` возвращает `"Book: 'Dune' by Herbert"`; для строки — `"Author name: ..."`, для числа — `"Publication year: ..."`, иначе — `"Unknown catalog item"`.
>
> ```scala
> def describeCatalogItem(item: Any): String =
>   item match
>     case Book(title, author, _, _) => s"Book: '$title' by $author"
>     case author: String  => s"Author name: $author"
>     case year: Int   => s"Publication year:  $year"
>     case _          => "Unknown catalog item"
> ```
>
> Пример показывает: проверяется структура объекта, не только значение.

##### Метапрограммирование и вычисления во время компиляции

Метапрограммирование переносит часть проверок и генерации кода на этап компиляции.

Inline-функции раскрываются компилятором: выше производительность, доступны дополнительные проверки.

> [!example]- Пример: inline-раскрытие
> `discountedPrice` — inline-функция, раскрывается компилятором.
>
> В `memberPrice` на этапе компиляции записывается 450.
>
> ```scala
> inline def discountedPrice(price: Int): Int = price - price / 10
>
> val memberPrice = discountedPrice(500) // раскрывается компилятором: 500 - 500 / 10 = 450
> ```
>
> Пример показывает: вычисление переносится на компиляцию, вызов без накладных расходов.

Некорректные вызовы обнаруживаются до запуска.

> [!example]- Пример: проверка на этапе компиляции
> `requirePositivePageCount` проверяет аргумент на этапе компиляции.
>
> Вызов с нулём или отрицательным значением — ошибка компиляции с текстом `"Page count must be positive!"`.
>
> ```scala
> import scala.compiletime.*
>
> inline def requirePositivePageCount(pages: Int): Int =
>   inline if pages > 0 then pages else error("Page count must be positive!")
> ```
>
> Пример показывает: проверки выполняются до запуска.
