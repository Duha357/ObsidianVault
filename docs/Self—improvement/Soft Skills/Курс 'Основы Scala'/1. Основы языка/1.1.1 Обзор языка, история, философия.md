## Общий обзор языка

Scala — язык программирования общего назначения, сочетающий объектно-ориентированную (ООП) и функциональную (ФП) парадигмы в рамках единой строго статически типизированной системы.

scalable — "масштабируемый" — отражает основную идею: один и тот же язык и стиль программирования подходят как для небольших утилит и скриптов, так и для крупных распределенных и корпоративных систем.

В отличие от многих функциональных языков, Scala не противопоставляет функциональный и объектно-ориентированный подходы, а интегрирует их на уровне базовых языковых конструкций.

## Краткая история языка

Scala был создан Мартином Одерски (Martin Odersky) и его командой. Язык вышел в 2004 году. Scala 2 — в 2006, Scala 3 — в 2021. Мартин Одерски ранее участвовал в разработке Java (в частности, дженериков), что существенно повлияло на архитектуру языка и совместимость с экосистемой JVM.

Scala 3 является логическим развитием Scala 2, а не отдельным языком: при проектировании большое внимание уделялось обратной совместимости и миграции существующего кода.

## Scala 3 и преемственность от Scala 2

Scala 3 сохраняет фундаментальные идеи Scala 2:

- классы и объекты
- трейты как средство композиции поведения
- сопоставление с образцом (pattern matching)
- функции как значения и функциональные абстракции
- богатую стандартную библиотеку и коллекции

Scala 3 существенно перерабатывает и упрощает ряд сложных и исторически нагруженных механизмов Scala 2, в первую очередь:

- систему implicits (заменена на более явные и структурированные механизмы given / using)
- синтаксис (уменьшение количества скобок и ключевых слов)
- сообщения об ошибках компилятора и диагностику

Для миграции кода существуют автоматизированные инструменты (например, sbt-scala3-migrate), позволяющие постепенно адаптировать проекты Scala 2 к Scala 3.

## Ключевые характеристики языка

Фундаментальные особенности, которые нужно держать в голове.

##### Интеграция с Java и JVM

Исторически полная совместимость с Java:

- код Scala компилируется в байткод JVM
- классы Scala могут напрямую использовать Java-библиотеки
- Scala-классы могут наследоваться от Java-классов и реализовывать Java-интерфейсы
- возможно поэтапное внедрение Scala в существующие Java-проекты

##### Функции как значения первого класса

Функции можно:

- присваивать переменным
- передавать в качестве аргументов
- возвращать из других функций
- хранить в структурах данных

Ключевое слово `val` определяет переменную.

```scala
val totalPages: (Int, Int) => Int = (firstBookPages, secondBookPages) => firstBookPages + secondBookPages
println(totalPages(320, 210)) // 500
```

##### Функции высшего порядка

Функции могут принимать другие функции в качестве параметров или возвращать их как результат.

Ключевое слово `def` определяет функцию.

```scala
def applyTwice(pages: Int, transform: Int => Int): Int =
  transform(transform(pages))

val addBonus = (pages: Int) => pages + 50 // каждое переиздание добавляет 50 страниц
println(applyTwice(200, addBonus)) // 300
```

##### Объекты как значения

Объекты часто используются как пространства имён, контейнеры утилитных функций или точки входа программы. Объекты, как и функции, являются значениями.

Ключевое слово `object` определяет одноэкземплярный объект (паттерн singleton).

```scala
object LibraryCatalog:
  def isLongRead(pages: Int): Boolean = pages > 400

val books = List(150, 520, 380, 670)
val longReads = books.filter(LibraryCatalog.isLongRead)
println(longReads) // List(520, 670)
```

##### Строго статическая типизация и вывод типов

Корректность типов и присваиваемых значений проверяется на этапе компиляции. При этом язык активно использует механизм автоматического определения типов, что сокращает количество явных аннотаций.

Тип может определиться без явных указаний:

```scala
val pageCount = 320 // Int
val title = "Dune" // String
```

Возвращаемый тип функции также может быть выведен автоматически:

```scala
def formatBookEntry(name: String, author: String) = s"$title by $author"
```

При несовместимости типов компилятор обнаруживает ошибку до выполнения программы:

```scala
val pageCount: Int = "three hundred" // ошибка компиляции
```

## Философия языка

##### Снижение синтаксического шума

Scala 3 стремится к более читаемому и предсказуемому синтаксису, особенно для управляющих конструкций.

Устремление к чёткому разделению, без лишних символов.

Scala 2:

```scala
def newerEdition(firstYear: Int, secondYear: Int): Int = {
  if (firstYear > secondYear) firstYear else secondYear
}
```

Scala 3:

```scala
def newerEdition(firstYear: Int, secondYear: Int): Int =
  if firstYear > secondYear then firstYear else secondYear
```

Отсутствие фигурных скобок и минимизация служебных слов делают код ближе к декларативному описанию логики.

##### Минимизация шаблонного кода

Предоставлены высокоуровневые конструкции для устранения повторяющегося кода.

При создании классов. Чтобы просто описать структуру, в старых языках (как Java) пришлось бы написать ~20 строк кода (конструкторы, геттеры, equals). В Scala это занимает одну строку.

При создании объектов. Вам не нужно постоянно писать слово `new`.

Не требуется прописывать `new Book` и другие уточняющие конструкции для создания экземпляра.

```scala
case class Book(name: String, author: String, year: Int, pages: Int)

val book = Book("The Master and Margarita", "Bulgakov", 1967, 480)
println(book)
```

`case class` автоматически генерирует:

- equals и hashCode
- toString
- метод copy
- поддержку сопоставления с другим экземпляром (образцом)

##### Сопоставление с образцом (Pattern Matching) или сравнение

Умное переключение течения кода на нужное направление. Оно не просто сравнивает значения, а проверяет, что именно находится внутри объекта (что в других языках может оказаться дорогостоящей операцией).

Выигрыш чаще заметен именно при работе с объектами и коллекциями, в отличие от строк или цифр.

Возможности предоставляются конструкцией `item match`; стандартный `if else` тоже доступен.

```scala
def describeCatalogItem(item: Any): String =
  item match
    case Book(title, author, _, _) => s"Book: '$title' by $author"
    case author: String  => s"Author name: $author"
    case year: Int   => s"Publication year:  $year"
    case _          => "Unknown catalog item"
```

##### Метапрограммирование и вычисления во время компиляции

Язык значительно расширяет возможности метапрограммирования, позволяя переносить часть логики проверки и генерации кода на этап компиляции.

Inline-функции могут быть раскрыты компилятором, что улучшает производительность и позволяет выполнять дополнительные проверки.

В переменную `memberPrice` ещё на этапе компиляции запишется 450.

```scala
inline def discountedPrice(price: Int): Int = price - price / 10

val memberPrice = discountedPrice(500) // раскрывается компилятором: 500 - 500 / 10 = 450
```

Некорректные вызовы могут быть обнаружены ещё до запуска программы.

Вызовы функции, прописанные в других местах кода с передачей нуля или отрицательного значения, вызовут ошибку компиляции.

```scala
import scala.compiletime.*

inline def requirePositivePageCount(pages: Int): Int =
  inline if pages > 0 then pages else error("Page count must be positive!")
```
