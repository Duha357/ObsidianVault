# Синтаксис и базовые конструкции Scala

## Значения, переменные и области видимости

---

## Значения и переменные

В Scala существуют два способа объявления именованных ссылок:

val libraryName = "City Library"  
var availableBooks = 120

### val — неизменяемая ссылка

val объявляет неизменяемую ссылку. Это означает:

- ссылку нельзя переназначить;
    
- после инициализации имя всегда указывает на один и тот же объект;
    
- гарантируется предсказуемость поведения.
    

Пример:

val mainAuthor = "Arthur Conan Doyle"  
// mainAuthor = "Agatha Christie"  // ошибка компиляции

Важно понимать: val делает неизменяемой ссылку, а не обязательно сам объект. Если объект изменяемый, его внутреннее состояние может меняться.

---

### var — изменяемая ссылка

var позволяет переназначать ссылку:

var borrowedBooks = 3  
borrowedBooks = borrowedBooks + 1

Использование var приближает код к императивному стилю. Однако в Scala 3 философия языка предполагает минимизацию изменяемости.

---

## Философия Scala 3: val по умолчанию

Scala поощряет использование val как стандартного способа объявления значений.

Причины:

1. Потокобезопасность — неизменяемые значения безопасны при параллельном доступе.
    
2. Предсказуемость — отсутствие скрытых изменений состояния.
    
3. Упрощённое тестирование — меньше неявных зависимостей.
    
4. Соответствие функциональной парадигме.
    

Практическое правило:

Используйте val всегда, если нет строгой необходимости в var.

## Вывод типов (Type Inference)

Scala обладает мощным механизмом вывода типов.

val bookCount = 42        // тип Int  
val authorName = "Tolkien"  // тип String

Компилятор выводит тип на основе правой части выражения.

### Когда указывать тип явно?

Явная аннотация типа рекомендуется:

- для публичных методов и API;
    
- при сложных обобщенных типах;
    
- когда нужно улучшить читаемость;
    
- для предотвращения нежелательного вывода более общего типа.
    

Пример:

val maxBooks: Int = 42

Синтаксис аннотации типа:

имя: Тип = значение

## Области видимости

Scala использует лексическую (статическую) область видимости.

Это означает:

- видимость имени определяется структурой кода;
    
- вложенные блоки имеют доступ к значениям внешних блоков;
    
- внешний код не видит внутренние объявления.
    

Пример:

val libraryName = "Central Library"  
  
{  
  val sectionName = "Science Fiction"   
  println(libraryName) // доступно  
}  
  
// println(sectionName) // ошибка: вне области видимости

---

## Вложенность блоков

Блок — это выражение в фигурных скобках:

val totalBooks = {  
  val fictionBooks = 40  
  val historyBooks = 25  
  fictionBooks + historyBooks  
}

Особенности:

- блок возвращает значение последнего выражения;
    
- переменные внутри блока недоступны снаружи;
    
- блоки позволяют локализовать временные значения.
    

Это отличает Scala от многих языков, где блок — лишь группа инструкций. В Scala блок — полноценное выражение.

---

## Перекрытие имен (Shadowing)

Shadowing — это объявление нового имени с тем же идентификатором во вложенной области.

Пример:

val bookTitle = "1984"  
  
{  
  val bookTitle = "Brave New World"  
  println(bookTitle) // Brave New World  
}  
  
println(bookTitle) // 1984

Внутренний bookTitle перекрывает внешний.

### Потенциальные проблемы

- ухудшение читаемости;
    
- риск логических ошибок;
    
- путаница при рефакторинге.
    

Рекомендуется избегать неочевидного перекрытия имён, особенно в больших функциях.
