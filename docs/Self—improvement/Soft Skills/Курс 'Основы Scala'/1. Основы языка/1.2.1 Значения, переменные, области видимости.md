## Синтаксис и базовые конструкции Scala

Базовые элементы языка: значения, переменные, области видимости, вывод типов. Синтаксис отражает философию Scala — безопасный, предсказуемый, выразительный код.

---

## Значения и переменные

Два способа объявления ссылок: `val` и `var`. Различие — в изменяемости ссылки.

> [!example]- Пример: объявление val и var
> Код объявляет `libraryName` через `val` и `availableBooks` через `var`.
>
> `libraryName` — "City Library", `availableBooks` — 120.
>
> ```scala
> val libraryName = "City Library"
> var availableBooks = 120
> ```
>
> Пример показывает: `val` и `var` — базовые способы объявления ссылок.

##### val — неизменяемая ссылка

`val` объявляет неизменяемую ссылку: переназначение запрещено, имя всегда указывает на один и тот же объект.

> [!example]- Пример: переназначение val
> Код объявляет `mainAuthor` через `val` и пытается переназначить.
>
> Строка `mainAuthor = "Agatha Christie"` — ошибка компиляции.
>
> ```scala
> val mainAuthor = "Arthur Conan Doyle"
> // mainAuthor = "Agatha Christie"  // ошибка компиляции
> ```
>
> Пример показывает: `val` запрещает переназначение ссылки.

`val` делает неизменяемой ссылку, не обязательно объект. Внутреннее состояние изменяемого объекта может меняться.

##### var — изменяемая ссылка

`var` допускает переназначение ссылки. Код приближается к императивному стилю.

> [!example]- Пример: переназначение var
> Код объявляет `borrowedBooks` через `var` и увеличивает на 1.
>
> `borrowedBooks` становится 4.
>
> ```scala
> var borrowedBooks = 3
> borrowedBooks = borrowedBooks + 1
> ```
>
> Пример показывает: `var` допускает переназначение ссылки.

##### Философия Scala 3: val по умолчанию

Scala поощряет `val` как стандартный способ объявления. Причины:

- Потокобезопасность: неизменяемые значения безопасны при параллельном доступе.
- Предсказуемость: нет скрытых изменений состояния.
- Упрощённое тестирование: меньше неявных зависимостей.
- Соответствие функциональной парадигме.

Правило: `val` всегда, если нет строгой необходимости в `var`.

## Вывод типов (Type Inference)

Компилятор выводит тип из правой части выражения.

> [!example]- Пример: вывод типов
> Код объявляет значения без аннотаций.
>
> `bookCount` — Int, `authorName` — String.
>
> ```scala
> val bookCount = 42        // тип Int
> val authorName = "Tolkien"  // тип String
> ```
>
> Пример показывает: тип выводится из правой части выражения.

##### Когда указывать тип явно

Явная аннотация типа рекомендуется:

- Для публичных методов и API.
- При сложных обобщённых типах.
- Для улучшения читаемости.
- Для предотвращения вывода более общего типа.

> [!example]- Пример: явная аннотация типа
> Код объявляет `maxBooks` с аннотацией `Int`.
>
> `maxBooks` — Int, тип задан явно.
>
> ```scala
> val maxBooks: Int = 42
> ```
>
> Пример показывает: синтаксис `имя: Тип = значение`.

## Области видимости

Scala использует лексическую (статическую) область видимости:

- Видимость имени определяется структурой кода.
- Вложенные блоки видят значения внешних блоков.
- **Не:**
	- Внешний код не видит внутренние объявления.

> [!example]- Пример: область видимости
> Код объявляет `libraryName` на внешнем уровне и `sectionName` внутри блока.
>
> Внутри блока `println(libraryName)` доступно; `println(sectionName)` вне блока — ошибка компиляции.
>
> ```scala
> val libraryName = "Central Library"
>
> {
>   val sectionName = "Science Fiction"
>   println(libraryName) // доступно
> }
>
> println(sectionName) // ошибка: вне области видимости
> ```
>
> Пример показывает: лексическая область видимости на практике — вложенные блоки видят внешние имена, доступ проверяется до запуска.

## Вложенность блоков

Блок `{ ... }` — выражение в фигурных скобках.

> [!example]- Пример: блок как выражение
> Код объявляет `totalBooks` блоком с двумя локальными значениями и суммой.
>
> `totalBooks` — 65 (40 + 25), `fictionBooks` и `historyBooks` снаружи недоступны.
>
> ```scala
> val totalBooks = {
>   val fictionBooks = 40
>   val historyBooks = 25
>   fictionBooks + historyBooks
> }
> ```
>
> Пример показывает: блок — полноценное выражение, возвращающее значение.

Особенности:

- Блок возвращает значение последнего выражения.
- Блоки локализуют временные значения.
- **Не:**
	- Переменные внутри блока недоступны снаружи.

Это отличает Scala от языков, где блок — лишь группа инструкций.

## Перекрытие имен (Shadowing)

Shadowing — объявление имени с тем же идентификатором во вложенной области.

> [!example]- Пример: перекрытие имени
> Код объявляет `bookTitle` на внешнем уровне и во вложенном блоке.
>
> Внутри блока `println(bookTitle)` — "Brave New World", снаружи — "1984".
>
> ```scala
> val bookTitle = "1984"
>
> {
>   val bookTitle = "Brave New World"
>   println(bookTitle) // Brave New World
> }
>
> println(bookTitle) // 1984
> ```
>
> Пример показывает: вложенное объявление с тем же именем перекрывает внешнее.

##### Потенциальные проблемы

- Ухудшение читаемости.
- Риск логических ошибок.
- Путаница при рефакторинге.

Рекомендация: избегать неочевидного перекрытия имён, особенно в больших функциях.
