# Операции с коллекциями

---

# Общая идея функциональной обработки

Вместо явных циклов и изменения состояния Scala предлагает декларативные операции над коллекциями.

Императивный стиль:

var result = List.empty[Int]  
for (pages <- List(100, 200, 300)) {  
  result = result :+ (pages * 2)  
}

Функциональный стиль:

List(100, 200, 300).map(_ * 2)

Функциональные операции:

- не изменяют исходную коллекцию;
    
- возвращают новую коллекцию;
    
- принимают функции как аргументы.
    

---

# map — преобразование 1 к 1

## Семантика

map применяет функцию к каждому элементу коллекции.

Тип:

map[A, B](f: A => B): Collection[B]

Пример:

val pageCounts = List(100, 200, 300)  
val doubledPages = pageCounts.map(_ * 2)  
// List(200, 400, 600)

Количество элементов сохраняется.

---

# filter — отбор элементов

## Семантика

filter оставляет только те элементы, для которых предикат возвращает true.

Тип:

filter(p: A => Boolean): Collection[A]

Пример:

val longBooks = pageCounts.filter(_ > 150)  
// List(200, 300)

Количество элементов может уменьшаться.

---

# flatMap — преобразование с разворачиванием

## Проблема вложенных коллекций

Если использовать map с функцией, возвращающей коллекцию:

List(100, 200, 300).map(pages => List(pages, pages))  
// List(List(100,100), List(200,200), List(300,300))

Получается вложенная структура.

---

## Решение через flatMap

flatMap объединяет два шага:

1. Применяет функцию.
    
2. “Разворачивает” вложенные коллекции.
    

List(100, 200, 300).flatMap(pages => List(pages, pages))  
// List(100,100,200,200,300,300)

Тип:

flatMap[A, B](f: A => Collection[B]): Collection[B]

---

## Связь с монадами

flatMap является основой:

- for-comprehension;
    
- работы с Option, Either, Future;
    
- композиции вычислений.
    

---

# foldLeft — левая свертка

## Идея

Свертка агрегирует коллекцию в одно значение.

Тип:

foldLeft[B](initial: B)(f: (B, A) => B): B

Пример:

val totalPages = List(100, 200, 300).foldLeft(0)(_ + _)  
// 600

Порядок вычисления:

((0 + 100) + 200) + 300

---

# foldRight — правая свертка

Тип:

foldRight[B](initial: B)(f: (A, B) => B): B

Пример:

List(1, 2, 3).foldRight(0)(_ + _)

Порядок:

1 + (2 + (3 + 0))

Полезен для прерывания обхода или работы с ленивыми структурами.

---

# Производительность: foldLeft vs foldRight

## Для List

- foldLeft — хвостовая рекурсия, безопасна по стеку;
    
- foldRight — может вызвать переполнение стека на больших списках.
    

Поэтому для List рекомендуется использовать foldLeft.

---

## Для других коллекций

Для строгих коллекций (например, Vector) различие менее критично.

Однако foldLeft обычно предпочтительнее.

---

# reduce — частный случай свертки

reduce агрегирует без начального значения.

List(100, 200, 300).reduce(_ + _)

Эквивалентно:

List(100, 200, 300).foldLeft(100)(_ + _)

Особенность:

- коллекция не должна быть пустой;
    
- иначе выбрасывается исключение.
    

Безопасная версия:

reduceOption

---

# Комбинирование операций

Операции можно комбинировать:

val result =  
  List(100, 200, 300, 400)  
.filter(_ > 150)  
.map(_ * 2)  
.foldLeft(0)(_ + _)

Это формирует декларативный конвейер обработки данных.
