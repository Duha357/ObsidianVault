# Частично применённые функции (Partial Application)

## Идея

Частичное применение — это фиксация части аргументов функции с получением новой функции с меньшим числом параметров.

Исходная функция:

def addBooks(firstShelf: Int, secondShelf: Int): Int = firstShelf + secondShelf

Частичное применение:

val addLibraryBooks: Int => Int = addBooks(100, _)

Теперь:

addLibraryBooks(50) // 150

Мы не изменили определение функции — мы зафиксировали один аргумент.

---

## Важно: это не PartialFunction

Частично применённая функция — это обычная функция.

Она:

- определена для всех допустимых входов;
    
- не содержит логики “определено/не определено”;
    
- не связана с типом PartialFunction.
    

---

# Частично определённые функции (PartialFunction)

## Идея

PartialFunction[A, B] — это функция, которая определена не для всех значений типа A.

Пример:

val bookCategory: PartialFunction[Int, String] =  
  case 1 => "Fantasy"  
  case 2 => "Science Fiction"

Эта функция:

- определена для 1 и 2;
    
- не определена для других значений.
    

---

## Методы PartialFunction

PartialFunction имеет два ключевых метода:

isDefinedAt(a: A): Boolean  
apply(a: A): B

Пример:

bookCategory.isDefinedAt(1) // true  
bookCategory.isDefinedAt(5) // false

Если вызвать bookCategory(3), будет выброшено исключение.

---

## orElse

Позволяет объединять частичные функции:

val fictionCategory: PartialFunction[Int, String] =  
  case 1 => "Fantasy"  
  
val scienceCategory: PartialFunction[Int, String] =  
  case 2 => "Science Fiction"  
  
val allCategories = fictionCategory.orElse(scienceCategory)

Теперь allCategories определена для 1 и 2.

---

## Где используются PartialFunction

- collect в коллекциях:
    

List(100, 200, 350).collect:  
  case pages if pages > 150 => pages + 50

- обработка сообщений (например, в акторных системах);
    
- декларативное описание правил.

# Каррирование

## Определение

Каррирование — преобразование функции нескольких аргументов в цепочку функций одного аргумента.

Исходный тип:

(A, B) => C

Каррированный тип:

A => B => C

---

## Пример

Некаррированная версия:

def calculatePages(bookCount: Int, pagesPerBook: Int): Int = bookCount * pagesPerBook

Каррированная версия:

def calculatePages(bookCount: Int)(pagesPerBook: Int): Int = bookCount * pagesPerBook

Использование:

val pagesForThreeBooks = calculatePages(3)  
pagesForThreeBooks(200) // 600

Здесь calculatePages(3) возвращает функцию Int => Int.

---

## Автоматическое каррирование

Функциональные значения можно каррировать через .curried:

val multiplyPages: (Int, Int) => Int = _ * _  
val curriedPages = multiplyPages.curried

---

# Группы параметров (Multiple Parameter Lists)

Scala позволяет объявлять функцию с несколькими списками параметров:

def calculateShelfCapacity(rows: Int)(booksPerRow: Int): Int = rows * booksPerRow

Это не просто синтаксис — это влияет на:

- каррирование;
    
- вывод типов;
    
- контекстные абстракции (using);
    
- частичное применение.
    

---

## Улучшение вывода типов

Группы параметров помогают компилятору выводить типы при передаче функций.

Пример (обобщенная функция):

def applyTo[A, B](a: A)(f: A => B): B = f(a)

Тип A выводится из первого списка параметров, что упрощает вызов.

---

## Удобство частичного применения

val multiplyBy2 = compute(2)

Если бы параметры были в одном списке, пришлось бы использовать _.

---

## Связь с контекстными параметрами

Множественные списки параметров используются для отделения:

- основных аргументов;
    
- контекстных аргументов (using).
    

Это фундамент для type classes и контекстных абстракций.

---

# Сравнение понятий

  

|   |   |
|---|---|
|Концепция|Смысл|
|Частичное применение|Фиксация части аргументов|
|PartialFunction|Функция, определённая не для всех входов|
|Каррирование|Преобразование в цепочку функций|
|Группы параметров|Синтаксис поддержки каррирования и вывода типов|
