# Управляющие конструкции

---

## Условная конструкция if / else

### if как выражение

В Scala if является выражением, а не инструкцией.

val bookStatus =  
  if availableBooks > 0 then "available"  
  else "out of stock"

Особенности:

- возвращает значение;
    
- тип определяется типами обеих ветвей;
    
- может быть вложенным;
    
- может использоваться в любом месте, где ожидается выражение.
    

Фактически if в Scala заменяет тернарный оператор (?:) из Java и C#.

---

### Отсутствие необходимости в return

Метод возвращает значение последнего выражения:

def calculateLateFee(daysLate: Int): Int =  
  if daysLate >= 0 then daysLate * 5 else 0

return не требуется и обычно не используется.

---

### Ветвление без else

Если else отсутствует:

if availableBooks > 0 then println("Books are available")

Тип выражения — Unit.

Это означает, что конструкция используется ради побочного эффекта.

## Цикл while

### Синтаксис

var shelfNumber = 1  
while shelfNumber <= 5 do  
  println(shelfNumber)  
  shelfNumber += 1

while:

- проверяет условие до выполнения тела;
    
- возвращает Unit;
    
- используется ради побочного эффекта.
    

---

### Рекомендации по использованию

while является императивной конструкцией. В функциональном стиле его использование минимизируется.

Предпочтительны:

- операции над коллекциями (map, fold, foreach);
    
- рекурсия;
    
- for-comprehensions.
    

while оправдан в:

- низкоуровневом коде;
    
- производительных вычислениях;
    
- взаимодействии с внешними API.

## Конструкция for

for в Scala — это универсальный механизм итерации и композиции.

### Генераторы

for bookTitle <- List("Dune", "Foundation", "Neuromancer") do  
  println(bookTitle)

bookTitle <- collection — генератор.

---

### Фильтры (guards)

for  
  bookPages <- List(120, 450, 90, 300)  
  if bookPages >= 200  
do  
  println(bookPages)

Фильтр ограничивает элементы, проходящие дальше.

---

### Вложенные генераторы

for  
  authorName <- List("Tolkien", "Rowling")  
  bookTitle <- List("The Lord of the Rings", "Harry Potter")  
do  
  println(s"$authorName - $bookTitle")

Создаётся декартово произведение.

---

### Использование yield

yield превращает for в выражение, создающее новую коллекцию.

val bookCodes =  
  for bookId <- List(1, 2, 3)  
  yield s"BOOK-$bookId"

Результат:

List("BOOK-1", "BOOK-2", "BOOK-3")

Без yield используется foreach (побочный эффект).

---

### Синтаксис Scala 3

Scala 3 допускает как фигурные скобки:

for (bookTitle <- books) {  
  println(bookTitle)  
}

так и отступный синтаксис:

for  
  bookTitle <- books  
do  
  println(bookTitle)

Рекомендуется придерживаться одного стиля в рамках проекта.

## Сопоставление с образцом (match)

match является альтернативой switch-case, но работает как выражение.

### Синтаксис

val bookDescription = bookCount match  
case 0 => "no books"  
case 1 => "single book"  
case _ => "many books"

  

Форма с фигурными скобками:

val bookDescription = bookCount match {  
case 0 => "empty library"  
case _ => "library has books"  
}

---

### Особенности

- возвращает значение;
    
- поддерживает типовые проверки;
    
- поддерживает деструктуризацию;
    
- проверяется компилятором на исчерпываемость (в ряде случаев).
    

---

### Пример с типами

def describeLibraryItem(item: Any): String =  
item match  
case pages: Int     => s"pages: $pages"  
case title: String  => s"title: $title"  
case _              => "unknown item"

match значительно мощнее традиционного switch.

## Сравнение конструкций

  

|   |   |   |
|---|---|---|
|Конструкция|Возвращает значение|Основное назначение|
|if|Да|Условное ветвление|
|while|Unit|Императивный цикл|
|for + yield|Да|Генерация коллекций|
|for без yield|Unit|Побочные эффекты|
|match|Да|Мощное ветвление|
