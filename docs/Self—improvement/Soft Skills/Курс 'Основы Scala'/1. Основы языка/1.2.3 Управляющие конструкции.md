## Управляющие конструкции

Управляющие конструкции Scala: `if`/`else`, `while`, `for`, `match`. `if` и `match` — выражения, `while` — императивный цикл.

---

## Условная конструкция if / else

`if` в Scala — выражение, не инструкция. Заменяет тернарный оператор `?:` из Java и C#.

##### if как выражение

`if` возвращает значение, тип определяется типами ветвей.

> [!example]- Пример: if как выражение
> Код присваивает результат `if` переменной `bookStatus`.
>
> При `availableBooks > 0` — "available", иначе — "out of stock".
>
> ```scala
> val bookStatus =
>   if availableBooks > 0 then "available"
>   else "out of stock"
> ```
>
> Пример показывает: `if` возвращает значение, тип определяется ветвями.

Характеристики:

- Возвращает значение.
- Тип определяется типами обеих ветвей.
- Может быть вложенным.
- Используется в любом месте, где ожидается выражение.

##### Отсутствие необходимости в return

Метод возвращает значение последнего выражения. `return` не требуется и обычно не используется.

> [!example]- Пример: неявный возврат
> Код объявляет функцию `calculateLateFee`, возвращающую результат `if`.
>
> `calculateLateFee(3)` возвращает 15, `calculateLateFee(-1)` — 0.
>
> ```scala
> def calculateLateFee(daysLate: Int): Int =
>   if daysLate >= 0 then daysLate * 5 else 0
> ```
>
> Пример показывает: `if` — последнее выражение, `return` не нужен.

##### Ветвление без else

Без `else` тип выражения — Unit. Конструкция используется ради побочного эффекта.

> [!example]- Пример: if без else
> Код вызывает `if` без ветки `else`.
>
> Тип выражения — Unit; `println` выполняется только при `availableBooks > 0`.
>
> ```scala
> if availableBooks > 0 then println("Books are available")
> ```
>
> Пример показывает: `if` без `else` — ради побочного эффекта.

## Цикл while

`while` — императивная конструкция: проверяет условие до тела, возвращает Unit, используется ради побочного эффекта.

##### Синтаксис

`while` проверяет условие до выполнения тела, тело повторяется, пока условие истинно.

> [!example]- Пример: синтаксис while
> Код объявляет `shelfNumber` и цикл `while`.
>
> Цикл выводит 1–5, `shelfNumber` доходит до 6.
>
> ```scala
> var shelfNumber = 1
> while shelfNumber <= 5 do
>   println(shelfNumber)
>   shelfNumber += 1
> ```
>
> Пример показывает: условие проверяется до выполнения тела.

##### Рекомендации по использованию

`while` минимизируется в функциональном стиле.

Предпочтительны:

- Операции над коллекциями: `map`, `fold`, `foreach`.
- Рекурсия.
- For-comprehensions.

`while` оправдан:

- В низкоуровневом коде.
- В производительных вычислениях.
- При взаимодействии с внешними API.

## Конструкция for

`for` — универсальный механизм итерации и композиции.

##### Генераторы

Генератор `x <- collection` задаёт источник элементов.

> [!example]- Пример: генератор for
> Код перебирает список названий книг генератором `bookTitle <- List(...)`.
>
> Выводит Dune, Foundation, Neuromancer.
>
> ```scala
> for bookTitle <- List("Dune", "Foundation", "Neuromancer") do
>   println(bookTitle)
> ```
>
> Пример показывает: генератор задаёт источник элементов.

##### Фильтры (guards)

Фильтр `if` ограничивает элементы, проходящие дальше.

> [!example]- Пример: фильтр в for
> Код перебирает количество страниц с фильтром `if bookPages >= 200`.
>
> Выводит 450 и 300: элементы меньше 200 отсеяны.
>
> ```scala
> for
>   bookPages <- List(120, 450, 90, 300)
>   if bookPages >= 200
> do
>   println(bookPages)
> ```
>
> Пример показывает: фильтр ограничивает элементы.

##### Вложенные генераторы

Вложенные генераторы создают декартово произведение.

> [!example]- Пример: вложенные генераторы
> Код перебирает два списка вложенными генераторами.
>
> Выводит 4 комбинации «автор - книга».
>
> ```scala
> for
>   authorName <- List("Tolkien", "Rowling")
>   bookTitle <- List("The Lord of the Rings", "Harry Potter")
> do
>   println(s"$authorName - $bookTitle")
> ```
>
> Пример показывает: вложенные генераторы создают комбинации.

##### Использование yield

`yield` превращает `for` в выражение, создающее новую коллекцию. Без `yield` — `foreach` (побочный эффект).

> [!example]- Пример: for ... yield
> Код строит `bookCodes` через `for ... yield`.
>
> `bookCodes` — `List("BOOK-1", "BOOK-2", "BOOK-3")`.
>
> ```scala
> val bookCodes =
>   for bookId <- List(1, 2, 3)
>   yield s"BOOK-$bookId"
> ```
>
> Пример показывает: `yield` создаёт новую коллекцию.

##### Синтаксис Scala 3

Scala 3 допускает фигурные скобки и отступный синтаксис. Рекомендуется один стиль в рамках проекта.

> [!example]- Пример: два синтаксиса for
> Код показывает `for` с фигурными скобками и с отступами.
>
> Обе формы эквивалентны, выводят названия книг.
>
> ```scala
> for (bookTitle <- books) {
>   println(bookTitle)
> }
> ```
>
> ```scala
> for
>   bookTitle <- books
> do
>   println(bookTitle)
> ```
>
> Пример показывает: Scala 3 поддерживает оба стиля.

## Сопоставление с образцом (match)

`match` — альтернатива `switch-case`, работает как выражение.

##### Синтаксис

`match` сопоставляет значение с образцами и возвращает результат первой подходящей ветки.

> [!example]- Пример: синтаксис match
> Код сопоставляет `bookCount` с образцами.
>
> При 0 — "no books", при 1 — "single book", иначе — "many books".
>
> ```scala
> val bookDescription = bookCount match
>   case 0 => "no books"
>   case 1 => "single book"
>   case _ => "many books"
> ```
>
> Пример показывает: `match` возвращает значение.

Форма с фигурными скобками:

> [!example]- Пример: match с фигурными скобками
> Код сопоставляет `bookCount` с образцами в фигурных скобках.
>
> При 0 — "empty library", иначе — "library has books".
>
> ```scala
> val bookDescription = bookCount match {
>   case 0 => "empty library"
>   case _ => "library has books"
> }
> ```
>
> Пример показывает: допустима форма с фигурными скобками.

##### Особенности

Характеристики `match`:

- Возвращает значение.
- Поддерживает типовые проверки.
- Поддерживает деструктуризацию.
- Проверяется компилятором на исчерпываемость (в ряде случаев).

##### Пример с типами

`match` поддерживает типовые проверки, в отличие от `switch`.

> [!example]- Пример: типовые проверки в match
> Код сопоставляет `item` типа `Any` с типовыми образцами.
>
> Для Int — "pages: N", для String — "title: ...", иначе — "unknown item".
>
> ```scala
> def describeLibraryItem(item: Any): String =
>   item match
>     case pages: Int    => s"pages: $pages"
>     case title: String => s"title: $title"
>     case _             => "unknown item"
> ```
>
> Пример показывает: `match` мощнее `switch` за счёт типовых проверок.

## Сравнение конструкций

Сравнение конструкций по возвращаемому значению и основному назначению.

| Конструкция | Возвращает значение | Основное назначение |
|---|---|---|
| if | Да | Условное ветвление |
| while | Unit | Императивный цикл |
| for + yield | Да | Генерация коллекций |
| for без yield | Unit | Побочные эффекты |
| match | Да | Мощное ветвление |
