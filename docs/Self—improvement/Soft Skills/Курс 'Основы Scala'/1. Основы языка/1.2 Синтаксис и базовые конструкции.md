# Синтаксис и базовые конструкции 

Данная лекция посвящена базовым синтаксическим элементам языка Scala и тем концепциям, которые лежат в их основе. Несмотря на внешнюю простоту, синтаксис Scala отражает ключевую философию языка: стремление к безопасному, предсказуемому и выразительному коду, пригодному для масштабируемых систем.

---

## Значения, переменные и области видимости

### Значения (val) и переменные (var)

В Scala существуют два основных способа объявления именованных сущностей:

val x = 10  
var y = 20

Ключевое различие между ними заключается в изменяемости ссылки.

---

### val — неизменяемая ссылка

Ключевое слово val (value) означает, что ссылка не может быть переназначена после инициализации:

val x = 10  
// x = 15 // ошибка компиляции

Важно подчеркнуть: val делает неизменяемой именно ссылку, а не обязательно объект, на который она указывает.

val list = scala.collection.mutable.ListBuffer(1, 2, 3)  
list += 4 // допустимо

В функциональном стиле программирования предпочтение отдаётся неизменяемым структурам данных:

val numbers = List(1, 2, 3)  
val updated = numbers :+ 4  
  
println(numbers) // List(1, 2, 3)  
println(updated) // List(1, 2, 3, 4)

Создается новый объект, а исходный остаётся неизменным.

---

### var — изменяемая ссылка

Ключевое слово var допускает переназначение значения:

var counter = 0  
counter = counter + 1

Это поведение аналогично переменным в большинстве императивных языков (Java, C++, C#).

---

### Философия Scala 3: предпочтение val

Scala следует принципу:

Неизменяемость по умолчанию — изменяемость по необходимости.

Использование val:

- снижает вероятность ошибок;
    
- упрощает рассуждение о программе;
    
- повышает безопасность в многопоточной среде;
    
- делает код ближе к функциональному стилю.
    

В конкурентных сценариях:

var shared = 0 // потенциальный race condition

в отличие от:

val shared = 0

Поэтому в Scala принято правило: использовать val всегда, если нет объективной необходимости в var.

---

## Вывод типов (Type Inference)

Scala обладает мощным механизмом вывода типов. Компилятор определяет тип значения на основе выражения справа от оператора присваивания:

val x = 42        // Int  
val name = "Bob"  // String  
val pi = 3.14     // Double

Типы не указаны явно, но они строго зафиксированы компилятором.

---

### Когда тип указывать явно

Явное указание типа рекомендуется:

- в сигнатурах публичных методов;
    
- когда тип неочевиден;
    
- для повышения читаемости и документирования кода.
    

val count: Int = 10  
val message: String = "Hello"

Синтаксис объявления типа:

имя: Тип

---

### Вывод типов и безопасность

Вывод типов не ослабляет строгую типизацию. Тип значения фиксируется при первой инициализации:

val x = 10  
// x = "Scala" // ошибка компиляции

Компилятор предотвращает любые несогласованные изменения типа.

## Области видимости (Scope)

Scala использует лексическую область видимости. Переменная доступна:

- внутри блока, где объявлена;
    
- во всех вложенных блоках;
    
- но недоступна за пределами этого блока.
    

### Пример вложенных областей

val a = 10  
  
def printValue(): Unit =  
  val b = 20  
  println(a)  
  println(b)  
  
printValue()  
// println(b) // ошибка компиляции

---

### Блок как выражение

В Scala блок кода { ... } является выражением и возвращает значение последнего выражения:

val result = {  
  val x = 10  
  val y = 20  
  x + y  
}  
  
println(result) // 30

Переменные x и y существуют только внутри блока.

---

### Перекрытие имен (Shadowing)

Scala допускает объявление переменной с тем же именем во вложенной области:

val x = 10  
{  
  val x = 20  
  println(x) // 20  
}  
println(x) // 10

Перекрытие может быть полезным для локализации логики, но при неосторожном использовании ухудшает читаемость. Рекомендуется избегать случайного shadowing и использовать осмысленные имена.

---

## Выражения и блоки кода

### Выражения и инструкции

В отличие от многих императивных языков, Scala построена вокруг выраженческой модели.

- Инструкция (statement) выполняет действие и не возвращает значение.
    
- Выражение (expression) вычисляется и возвращает значение.
    

В Scala почти всё является выражением: арифметика, if, match, блоки кода.

---

### if как выражение

val y = if x > 5 then 10 else 20

if возвращает значение, что позволяет обходиться без var и побочных эффектов.

Тип результата определяется по веткам:

val result = if true then 1 else 2      // Int  
val value  = if true then 1 else "one" // Any

---

### Блоки и возврат значений

Функции возвращают значение последнего выражения, ключевое слово return не требуется:

def square(x: Int): Int =  
  x * x

return существует, но используется редко, так как нарушает выраженческую модель.

---

### Тип Unit

Некоторые выражения возвращают тип Unit — аналог void:

println("Hello") // Unit

Формально это выражение, но его значение не несёт полезной информации.

---

## Управляющие конструкции

### if / else

if используется как выражение и заменяет тернарный оператор:

val result = if x > 0 then "positive" else "non-positive"

---

### while

while используется для императивных циклов и возвращает Unit:

var i = 0  
while i < 3 do  
  println(i)  
  i += 1

В Scala рекомендуется по возможности заменять while функциональными конструкциями.

---

### for и for ... yield

for — мощный синтаксический сахар для работы с коллекциями:

val squares = for x <- List(1, 2, 3, 4) yield x * x

for поддерживает фильтры и вложенные генераторы и полностью совместим с функциональным стилем.

---

### match

match — универсальный механизм сопоставления с образцом:

val result = x match  
  case 0 => "zero"  
  case 1 => "one"  
  case _ => "many"

В отличие от switch, match:

- является выражением;
    
- проверяется компилятором на полноту;
    
- поддерживает условия и деструктуризацию.
