## Синтаксис и базовые конструкции

Базовые синтаксические элементы Scala отражают философию языка: безопасный, предсказуемый и выразительный код для масштабируемых систем.

---

## Значения, переменные и области видимости

##### Значения (val) и переменные (var)

Два способа объявления именованных сущностей. Различие — в изменяемости ссылки.

> [!example]- Пример: объявление val и var
> Код объявляет `x` через `val` и `y` через `var`.
>
> `x = 10`, `y = 20`.
>
> ```scala
> val x = 10
> var y = 20
> ```
>
> Пример показывает: `val` и `var` — базовые способы объявления значений.

##### val — неизменяемая ссылка

`val` (value) — ссылка не переназначается после инициализации. Неизменяема ссылка, не обязательно объект.

> [!example]- Пример: переназначение val
> Код объявляет `x` через `val` и пытается переназначить.
>
> Строка `x = 15` — ошибка компиляции.
>
> ```scala
> val x = 10
> // x = 15 // ошибка компиляции
> ```
>
> Пример показывает: `val` запрещает переназначение ссылки.

> [!example]- Пример: val с изменяемым объектом
> Код объявляет изменяемый `ListBuffer` через `val` и добавляет элемент.
>
> `list += 4` допустимо, список меняется.
>
> ```scala
> val list = scala.collection.mutable.ListBuffer(1, 2, 3)
> list += 4 // допустимо
> ```
>
> Пример показывает: `val` фиксирует ссылку, объект может быть изменяемым.

> [!example]- Пример: неизменяемая коллекция
> Код объявляет список `numbers` и создаёт `updated` операцией `:+`.
>
> `numbers` — `List(1, 2, 3)`, `updated` — `List(1, 2, 3, 4)`, исходный список не изменён.
>
> ```scala
> val numbers = List(1, 2, 3)
> val updated = numbers :+ 4
>
> println(numbers) // List(1, 2, 3)
> println(updated) // List(1, 2, 3, 4)
> ```
>
> Пример показывает: создаётся новый объект, исходный остаётся.

##### var — изменяемая ссылка

`var` допускает переназначение значения. Поведение аналогично переменным императивных языков (Java, C++, C#).

> [!example]- Пример: переназначение var
> Код объявляет `counter` через `var` и увеличивает его.
>
> `counter` становится 1.
>
> ```scala
> var counter = 0
> counter = counter + 1
> ```
>
> Пример показывает: `var` допускает переназначение.

##### Философия Scala 3: предпочтение val

Принцип: неизменяемость по умолчанию, изменяемость по необходимости.

Использование `val`:

- Снижает вероятность ошибок.
- Упрощает рассуждение о программе.
- Повышает безопасность в многопоточной среде.
- Делает код ближе к функциональному стилю.

> [!example]- Пример: var в конкурентном сценарии
> Код объявляет `shared` через `var` в конкурентном сценарии.
>
> Изменение `var shared` из нескольких потоков — race condition; `val shared` переназначить невозможно.
>
> ```scala
> var shared = 0 // потенциальный race condition
> ```
>
> Пример показывает: `var` создаёт риск гонок, `val` исключает.

Правило: `val` всегда, если нет объективной необходимости в `var`.

## Вывод типов (Type Inference)

Компилятор определяет тип по выражению справа от присваивания. Типы не указаны явно, но строго зафиксированы.

> [!example]- Пример: вывод типов
> Код объявляет значения без явных аннотаций.
>
> `x` — Int, `name` — String, `pi` — Double.
>
> ```scala
> val x = 42        // Int
> val name = "Bob"  // String
> val pi = 3.14     // Double
> ```
>
> Пример показывает: типы выводятся из инициализатора.

##### Когда тип указывать явно

Явное указание типа рекомендуется:

- В сигнатурах публичных методов.
- Когда тип неочевиден.
- Для повышения читаемости и документирования кода.

> [!example]- Пример: явная аннотация типа
> Код объявляет значения с явными аннотациями.
>
> `count` — Int, `message` — String, типы заданы явно.
>
> ```scala
> val count: Int = 10
> val message: String = "Hello"
> ```
>
> Пример показывает: синтаксис `имя: Тип`.

##### Вывод типов и безопасность

Вывод типов не ослабляет строгую типизацию. Тип фиксируется при первой инициализации.

> [!example]- Пример: фиксация типа
> Код объявляет `x` через `val` и пытается присвоить строку.
>
> Строка `x = "Scala"` — ошибка компиляции.
>
> ```scala
> val x = 10
> // x = "Scala" // ошибка компиляции
> ```
>
> Пример показывает: тип фиксируется при инициализации.

## Области видимости (Scope)

Лексическая область видимости:

- Доступна внутри блока, где объявлена.
- Доступна во всех вложенных блоках.
- **Не:**
  - Недоступна за пределами блока.

##### Вложенные области

Вложенные блоки и функции видят переменные внешних областей.

> [!example]- Пример: вложенные области
> Код объявляет `a` на верхнем уровне и `b` внутри `printValue`.
>
> `printValue()` выводит 10 и 20; `println(b)` вне функции — ошибка компиляции.
>
> ```scala
> val a = 10
>
> def printValue(): Unit =
>   val b = 20
>   println(a)
>   println(b)
>
> printValue()
> // println(b) // ошибка компиляции
> ```
>
> Пример показывает: внутренняя область видит внешнюю, обратная видимость недоступна.

##### Блок как выражение

Блок `{ ... }` — выражение, возвращает значение последнего выражения.

> [!example]- Пример: блок как выражение
> Код объявляет `result` блоком с двумя локальными значениями и суммой.
>
> `result` — 30, `x` и `y` существуют только внутри блока.
>
> ```scala
> val result = {
>   val x = 10
>   val y = 20
>   x + y
> }
>
> println(result) // 30
> ```
>
> Пример показывает: блок возвращает значение последнего выражения.

##### Перекрытие имен (Shadowing)

Вложенная область может объявлять переменную с тем же именем. Shadowing локализует логику, но ухудшает читаемость.

> [!example]- Пример: перекрытие имени
> Код объявляет `x` на внешнем уровне и `x` во вложенном блоке.
>
> Внутри блока `println(x)` — 20, снаружи — 10.
>
> ```scala
> val x = 10
> {
>   val x = 20
>   println(x) // 20
> }
> println(x) // 10
> ```
>
> Пример показывает: вложенное объявление перекрывает внешнее.

Случайного shadowing избегать, использовать осмысленные имена.

## Выражения и блоки кода

Scala построена вокруг выраженческой модели.

- Инструкция (statement) выполняет действие и не возвращает значение.
- Выражение (expression) вычисляется и возвращает значение.

Почти всё — выражение: арифметика, if, match, блоки кода.

##### if как выражение

`if` возвращает значение, заменяет тернарный оператор, позволяет без `var` и побочных эффектов.

> [!example]- Пример: if как выражение
> Код присваивает результат `if` переменной.
>
> `y` — 10 при `x > 5`, иначе 20.
>
> ```scala
> val y = if x > 5 then 10 else 20
> ```
>
> Пример показывает: `if` возвращает значение.

Тип результата определяется по веткам:

> [!example]- Пример: тип результата if
> Код вычисляет тип результата по веткам.
>
> `result` — Int, `value` — Any.
>
> ```scala
> val result = if true then 1 else 2       // Int
> val value  = if true then 1 else "one"  // Any
> ```
>
> Пример показывает: тип результата — общий тип веток.

##### Блоки и возврат значений

Функция возвращает значение последнего выражения, `return` не требуется. `return` используется редко — нарушает выраженческую модель.

> [!example]- Пример: неявный возврат
> Код объявляет функцию `square` без `return`.
>
> `square(4)` возвращает 16 — значение последнего выражения.
>
> ```scala
> def square(x: Int): Int =
>   x * x
> ```
>
> Пример показывает: `return` не требуется.

##### Тип Unit

Некоторые выражения возвращают Unit — аналог void. Формально это выражение, но значение не несёт полезной информации.

> [!example]- Пример: тип Unit
> Код вызывает `println`.
>
> `println("Hello")` возвращает Unit.
>
> ```scala
> println("Hello") // Unit
> ```
>
> Пример показывает: Unit — аналог void.

## Управляющие конструкции

Управляющие конструкции: `if`/`else`, `while`, `for`, `match`.

##### if / else

`if` используется как выражение и заменяет тернарный оператор.

> [!example]- Пример: if / else
> Код присваивает результат `if` строке.
>
> `result` — "positive" при `x > 0`, иначе "non-positive".
>
> ```scala
> val result = if x > 0 then "positive" else "non-positive"
> ```
>
> Пример показывает: `if` заменяет тернарный оператор.

##### while

`while` — императивный цикл, возвращает Unit. Рекомендуется заменять функциональными конструкциями.

> [!example]- Пример: while
> Код объявляет `i` и цикл `while`.
>
> Цикл выводит 0, 1, 2, `i` доходит до 3.
>
> ```scala
> var i = 0
> while i < 3 do
>   println(i)
>   i += 1
> ```
>
> Пример показывает: `while` — императивный цикл.

##### for и for ... yield

`for` — синтаксический сахар для работы с коллекциями. Поддерживает фильтры и вложенные генераторы, совместим с функциональным стилем.

> [!example]- Пример: for ... yield
> Код строит `squares` через `for ... yield`.
>
> `squares` — `List(1, 4, 9, 16)`.
>
> ```scala
> val squares = for x <- List(1, 2, 3, 4) yield x * x
> ```
>
> Пример показывает: `for ... yield` — функциональная работа с коллекциями.

##### match

`match` — механизм сопоставления с образцом.

В отличие от switch:

- Является выражением.
- Проверяется компилятором на полноту.
- Поддерживает условия и деструктуризацию.

> [!example]- Пример: match
> Код сопоставляет `x` с образцами.
>
> При `x = 0` — "zero", при `x = 1` — "one", иначе — "many".
>
> ```scala
> val result = x match
>   case 0 => "zero"
>   case 1 => "one"
>   case _ => "many"
> ```
>
> Пример показывает: `match` — выражение с проверкой на полноту.
