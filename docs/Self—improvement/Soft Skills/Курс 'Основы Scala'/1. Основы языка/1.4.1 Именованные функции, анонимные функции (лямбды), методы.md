## Методы (def)

В Scala функции, объявленные через `def`, — методы: члены класса или объекта.

> [!example]- Пример: Объявление метода
> Метод `countPages` объявлен через `def` и принадлежит объекту `LibraryUtils`.
>
> Вызов `countPages(150)` вернёт `300`.
>
> ```scala
> object LibraryUtils:
>   def countPages(pages: Int): Int =
>     pages * 2
> ```
>
> Пример показывает: синтаксис объявления метода.

Особенности метода:

- Объявляется с помощью ключевого слова `def`.
- Принадлежит классу или объекту.
- Не является значением сам по себе.
- Вычисляется при каждом вызове.

> [!example]- Пример: Вызов метода
> Метод вызывается через объект-владельца.
>
> Результат вызова `LibraryUtils.countPages(150)` — `300`.
>
> ```scala
> LibraryUtils.countPages(150)
> ```
>
> Пример показывает: обращение к методу через объект-владельца.

Метод — поведение, связанное с типом.

## Именованные функции как значения

В Scala функция может быть значением.

Тип функции записывается как `(Int) => Int`.

> [!example]- Пример: Функция как значение
> Лямбда `(pages: Int) => pages * 2` присваивается значению `increasePages`.
>
> `increasePages` имеет тип `Int => Int`; для `150` вернёт `300`.
>
> ```scala
> val increasePages: Int => Int =
>   (pages: Int) => pages * 2
> ```
>
> Пример показывает: присваивание лямбды значению с явным типом функции.

Здесь:

- `(pages: Int) => pages * 2` — лямбда-выражение.
- `increasePages` — значение, содержащее функцию.

Такое значение — объект, реализующий трейт `Function1[Int, Int]`.

## Анонимные функции (лямбды)

Анонимная функция: параметр, стрелка `=>`, тело. Тип параметра указывается в скобках.

> [!example]- Пример: Лямбда с типом параметра
> Лямбда `(bookCount: Int) => bookCount * 2` объявлена с аннотацией типа параметра.
>
> Выражение имеет тип `Int => Int`; вызов с `150` вернёт `300`.
>
> ```scala
> (bookCount: Int) => bookCount * 2
> ```
>
> Пример показывает: базовый синтаксис анонимной функции.

Тип параметра можно опустить, если компилятор выводит его из контекста:

> [!example]- Пример: Лямбда без типа параметра
> Параметр `bookCount` указан без аннотации типа.
>
> Тип `Int` выводится из аннотации значения `doublePages`.
>
> ```scala
> val doublePages: Int => Int = bookCount => bookCount * 2
> ```
>
> Пример показывает: опускание типа параметра при выводимости.

Использование с коллекциями:

> [!example]- Пример: Лямбда в методе коллекции
> `map` применяет лямбду к каждому элементу списка.
>
> Результат — `List(150, 250, 350)`.
>
> ```scala
> List(100, 200, 300).map(bookPages => bookPages + 50)
> ```
>
> Пример показывает: передачу лямбды в `map`.

## Синтаксический сахар

Если параметр используется один раз, можно применить сокращённую форму с `_`:

> [!example]- Пример: Сокращённая форма с `_`
> `_` заменяет единственный параметр лямбды.
>
> Результат — `List(150, 250, 350)`.
>
> ```scala
> List(100, 200, 300).map(_ + 50)
> ```
>
> Пример показывает: замену параметра на `_` при однократном использовании.

Полная запись с именованным параметром эквивалентна сокращённой форме:

> [!example]- Пример: Полная форма лямбды
> Параметр `bookPages` назван явно, без `_`.
>
> Результат — тот же список `List(150, 250, 350)`.
>
> ```scala
> List(100, 200, 300).map(bookPages => bookPages + 50)
> ```
>
> Пример показывает: развёрнутую запись формы с `_`.

- `_` можно использовать, если каждый параметр встречается ровно один раз.
- При нескольких параметрах используются несколько подчёркиваний.

> [!example]- Пример: Несколько параметров с `_`
> `_ + _` заменяет два параметра лямбды.
>
> Результат — значение типа `(Int, Int) => Int`.
>
> ```scala
> val totalPages: (Int, Int) => Int = _ + _
> ```
>
> Пример показывает: использование `_` для каждого параметра.

## Метод vs функция

Метод и функциональное значение — разные сущности в Scala.

##### Метод

Метод объявляется через `def` и принадлежит классу или объекту.

> [!example]- Пример: Метод с несколькими параметрами
> Метод `addBooks` объявлен через `def` и складывает два аргумента.
>
> Вызов `addBooks(2, 3)` вернёт `5`.
>
> ```scala
> def addBooks(firstShelf: Int, secondShelf: Int): Int = firstShelf + secondShelf
> ```
>
> Пример показывает: синтаксис метода с параметрами и типом результата.

- Принадлежит классу или объекту.
- Не является объектом.
- Не имеет типа `FunctionN` напрямую.

##### Функциональное значение

Функциональное значение — объект с типом `FunctionN`.

> [!example]- Пример: Функциональное значение
> `addBooksFn` — значение, которому присвоена лямбда сложения.
>
> Тип значения — `(Int, Int) => Int`, то есть `Function2[Int, Int, Int]`.
>
> ```scala
> val addBooksFn: (Int, Int) => Int = (firstShelf, secondShelf) => firstShelf + secondShelf
> ```
>
> Пример показывает: присваивание лямбды значению с типом функции.

- Является объектом.
- Имеет тип `Function2[Int, Int, Int]`.
- Может передаваться как аргумент.

## Eta-расширение (преобразование метода в функцию)

Метод можно преобразовать в функцию.

> [!example]- Пример: Eta-расширение через `_`
> `calculateBooks _` преобразует метод `calculateBooks` в функцию.
>
> Результат — `calculateBooksFn` типа `(Int, Int) => Int`.
>
> ```scala
> def calculateBooks(boxes: Int, booksPerBox: Int): Int = boxes * booksPerBox
>
> val calculateBooksFn = calculateBooks _
> ```
>
> Пример показывает: преобразование метода в функцию через подчёркивание.

Подчёркивание инициирует eta-расширение.

Теперь `calculateBooksFn` имеет тип `(Int, Int) => Int`.

В Scala 3 eta-расширение часто происходит автоматически, если контекст ожидает функцию:

> [!example]- Пример: Автоматическое eta-расширение
> Компилятор преобразует метод `countPages` в функцию.
>
> Результат — `List(200, 400, 600)`.
>
> ```scala
> List(100, 200, 300).map(LibraryUtils.countPages)
> ```
>
> Пример показывает: автоматическое преобразование метода в функцию в Scala 3.

## Практическое сравнение

Ключевые различия метода и функции.

| Характеристика | Метод (def) | Функция (val f = ...) |
|---|---|---|
| Является значением | Нет | Да |
| Принадлежит классу | Да | Может быть любым значением |
| Может передаваться напрямую | Через eta | Да |
| Тип | Не FunctionN | FunctionN |

## Использование в коллекциях

Функции активно используются в API коллекций:

> [!example]- Пример: Функции в API коллекций
> `map` добавляет 10 к каждому элементу, `filter` оставляет элементы больше 200.
>
> Результат: `map` — `List(110, 210, 310)`, `filter` — `List(300)`, `foldLeft` — `600`.
>
> ```scala
> val bookPages = List(100, 200, 300)
>
> bookPages.map(_ + 10)
> bookPages.filter(_ > 200)
> bookPages.foldLeft(0)(_ + _)
> ```
>
> Пример показывает: передачу функций в методы коллекций.
