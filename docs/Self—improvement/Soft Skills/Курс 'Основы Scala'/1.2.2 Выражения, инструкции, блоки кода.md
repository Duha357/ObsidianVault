# Выражения, инструкции и блоки кода в Scala

---

## Expression vs Statement

### Инструкция (statement)

В классических императивных языках инструкция:

- выполняет действие;
    
- не обязана возвращать значение;
    
- используется ради побочного эффекта.
    

Пример (Java-подобный подход):

if (bookCount > 0) {  
    System.out.println("Books available");  
}

if здесь — инструкция, не возвращающая значение.

---

### Выражение (expression)

Выражение:

- вычисляется;
    
- всегда возвращает значение;
    
- может быть частью более крупного выражения.
    

В Scala почти всё является выражением.

---

## Почти всё — выражение

### Арифметические операции

val totalBooks = 15 + 25

15 + 25 — выражение типа Int.

---

### Условные конструкции

В Scala if — это выражение:

val libraryStatus =  
  if bookCount > 0 then "open"  
  else "empty"

if возвращает значение, и его тип определяется типами ветвей.

Если типы различаются, компилятор выводит их общий супертип.

---

### Match-выражения

val bookCategory = bookCount match  
  case 0 => "no books"  
  case n => s"books: $n"

match также возвращает значение.

---

### Блок как выражение

val availableBooks = {  
  val fictionBooks = 10  
  val scienceBooks = 20  
  fictionBooks + scienceBooks  
}

Блок { ... }:

- объединяет несколько выражений;
    
- возвращает значение последнего выражения;
    
- имеет собственную область видимости.
    

Это ключевая особенность Scala: блок — полноценное выражение.

---

## Отсутствие необходимости в return

В Scala возвращаемым значением метода является последнее выражение.

Пример:

def doubleBook(count: Int): Int =  
  count * 2

Здесь count * 2 — возвращаемое значение.

Можно использовать return, но это не идиоматично:

def doubleBook(count: Int): Int =  
  return count * 2

Использование return:

- нарушает функциональный стиль;
    
- вводит императивную семантику преждевременного выхода;
    
- редко применяется в реальном Scala-коде.
    

Рекомендуется полагаться на последнее выражение.

---

## Побочные эффекты и тип Unit

Если выражение используется ради эффекта, оно возвращает тип Unit.

val result = println("New book added")

Тип result — Unit.

Unit — аналог void в Java, но в отличие от void, это полноценный тип с единственным значением ().

---

## Точка с запятой

В Scala точка с запятой необязательна.

val authorName = "Tolkien"  
val bookTitle = "The Hobbit"

Компилятор использует перевод строки как разделитель выражений.

Точка с запятой требуется только если несколько выражений расположены на одной строке:

val authorName = "Rowling"; val bookTitle = "Harry Potter" 

Или при синтаксической необходимости (редкие случаи при сложных выражениях).

Идиоматический стиль — одна инструкция на строку без ;.

---

## Практическое сравнение с Java

  

|   |   |   |
|---|---|---|
|Концепция|Java|Scala|
|if|инструкция|выражение|
|switch|инструкция|match-выражение|
|блок|группа инструкций|выражение|
|return|обязателен|не требуется|
|void|не тип|Unit — тип|

Scala приближает синтаксис к функциональной модели, где программы состоят из композиций выражений.
