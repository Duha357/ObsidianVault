## Классы типов (Type Classes)

---

## Проблема ООП-интерфейсов

Паттерн Type classes решает похожую проблему, которую решают расширения-методы.

Для того, чтобы добавить к какому-то классу интерфейс в стиле ООП, делают наследование от интерфейса (Implements Comparable).

Проблема возникает, если нам нужно работать с классом из какой-то другой библиотеки, и мы хотим добавить к нему интерфейс. Паттерн type classes позволяет подключить новый интерфейс к объекту извне, не изменяя код самого объекта

Суть паттерна заключается в том, что мы разделяем данные и поведение для них.

Паттерн состоит из 3 шагов:

---

## 1. Описание поведения (Интерфейс)

Сначала нужно создать тип, который позволит превращать некий тип A в строку.

trait Show[A]:  
  def show(a: A): String

---

## 2. Реализация

Далее нужно создать правило для конкретного типа. Например, в случае работы с числом будем вызывать метод toString. Компилятор будет знать, как работать конкретно с этим типом.

given Show[Int] with  
  def show(a: Int): String = a.toString

---

## 3. Использование

## Чтобы можно было использовать метод лаконично (с помощью точки), нужно добавить изученный ранее метод расширения:

extension [A](a: A)  
  def show(using s: Show[A]): String =  
    s.show(a)

42.show

Этот код добавит метод к любому объекту, если сможет найти его на шаге 2.

---

## Сценарии использования

В работе не так часто нужно создавать классы типов, обычно используются уже готовые. Самые частые примеры:

- Ordering. При вызове метода .sorted, компилятор ищет класс типов для элементов внутри списка
    
- Работа с json. Любые библиотеки для работы с API используют этот паттерн, чтобы понимать, по каким правилам превращать case-class в json
    

 Рассмотрим, как классы типов выглядят в Scala 2. Используем ключевое слово implicit

## 1. Описание поведения (Интерфейс)

Шаг 1 аналогичен примеру из Scala 3

trait Show[A]:  
  def show(a: A): String

---

## 2. Реализация

implicit val intShow: Show[Int] = new Show[Int] {

  def show(a: Int): String = a.toString()

} 

---

## 3. Использование

Метод расширения принимает неявный параметр

implicit class ShowOps[A](val a: A) extends AnyVal {

  def show(implicit s: Show[A]): String = s.show(a) 

}  

Механика работы идентична: компилятор ищет подходящий implicit в области видимости и подставляет его
