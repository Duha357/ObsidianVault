### Pattern matching и частичные функции

## Углублённый pattern matching

Pattern matching (сопоставление с шаблоном) похож на switch в других языках программирования, но гораздо мощнее. С помощью этой конструкции можно не только сравнивать значения, но и разбирать объекты на составные части,т.е. декомпозировать.

В функциональном программировании pattern matching - основной инструмент управления бизнес-логикой, вместо множества if-else

Пример:

def describeItem(item: Any): String = item match

  case "Harry Potter" => "Это бестселлер!"

  case pages: Int     => s"В книге $pages страниц"

  case book: Book     => s"Книга: ${book.title}"

  case _              => "Неизвестный предмет" 

Свойства pattern matching:

- работает как выражение;
    
- возвращает значение;
    
- поддерживает декомпозицию объектов;
    
- проверяется компилятором на исчерпываемость (в случае sealed иерархий);
    
- поддерживает дополнительные условия (case x if condition =>).
    

В функциональном стиле pattern matching является ключевым инструментом управления потоком выполнения.

## Пользовательские экстракторы (unapply)

Экстракторы используются, чтобы декомпозировать объект в pattern matching. Он реализуется в методе unapply в объекте-компаньоне.

object Email:  
  def unapply(str: String): Option[(String, String)] =  
    str.split("@") match  
      case Array(user, domain) => Some((user, domain))  
      case _                   => None

Использование:

"john@example.com" match  
  case Email(user, domain) =>  
    println(s"user=$user, domain=$domain")  
  case _ =>  
    println("not an email")

Механизм работы:

- компилятор вызывает Email.unapply(john@example.com);
    
- если возвращается Some, происходит декомпозиция;
    
- если None, сопоставление не выполняется.
    

Экстракторы:

- расширяют возможности pattern matching;
    
- позволяют скрывать сложную логику разбора;
    
- дают возможность строить DSL для сопоставления.

## unapplySeq — переменное число элементов

Иногда неизвестно, на сколько частей в итоге можно разбить данные. Для этого используется экстрактор unapplySeq, который возвращает последовательность

object Path:  
  def unapplySeq(path: String): Option[Seq[String]] =  
    Some(path.split("/").toSeq)  
  
"/usr/local/bin" match  
  case Path("usr", rest*) => println(rest)

Символ * означает, что нужно взять все оставшиеся элементы.

unapplySeq применяется при работе со строками, путями, аргументами и другими структурами переменной длины.

## PartialFunction

Обычная функция может работать с любыми данными своего типа. Частичная функция (PartialFunction[A, B]) умеет обрабатывать только определенные значения, а остальные игнорирует.Пример:

val genreMap: PartialFunction[Int, String] =

  case 1 => "Fantasy"

  case 2 => "Science Fiction" 

Здесь функция умеет работать только с 1 и 2.

## Проверка применимости

При передаче в функцию pf значения 3, программа упадет с ошибкой MatchError. Поэтому перед вызовом функции нужно проверить, подходит ли значение.

pf.isDefinedAt(3) // false

Более безопасный способ - использовать lift. Этот метод преобразует частичную функцию в обычную, которая возвращает Option.

val lifted: Int => Option[String] = pf.lift  
  
lifted(1) // Some("one")  
lifted(5) // None

## Композиция частичных функций

С помощью методов orElse можно комбинировать частичные функции. Если первая функция не знает, как обработать это значение, то будет использоваться вторая, то будет использоваться вторая.

Частичные функции можно комбинировать.

val pf2: PartialFunction[Int, String] =  
  case 3 => "three"  
  
val combined = pf.orElse(pf2)

Также можно использовать andThen, в таком случае вторая функция будет применена к результату первой

## Цепочки case на практике

Зачастую частичные функции не сохраняют в отдельных переменных, а блоки case передают внутрь других переменных.

// Список из разных данных в системе

val items = List("просто текст", Book("Шоколад"), 42, Book("Леденцовые туфельки"))

  

val booksOnly = items.collect {

  case b: Book => b.title 

} // List("Шоколад", "Леденцовые туфельки")**
