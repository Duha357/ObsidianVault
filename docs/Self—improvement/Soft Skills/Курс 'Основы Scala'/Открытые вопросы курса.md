## 1. Внешние продукты и инструменты

##### Global ERP и «фреймворк»

Упоминается 4 раза, ни разу не расшифровывается.

- `2.1.1` — «В бизнес-логике фреймворка вместо `private` чаще применяется `protected`… при проектной разработке».
- `2.1.2` — «Во фреймворке применяются фабричные методы», пример с `List_ForChoose` и `TypeTag`.
- `2.1.3` — «Во фреймворке классы разделены по роли», упоминаются `BookApi` и таблицы БД.
- `2.3.1` — «Во фреймворке применяются оба подхода».

В плане курса Global ERP назван прямо: легенда плашек и пункт 1.3.5. В материалах — только «фреймворк».

Варианты: расшифровать один раз во введении либо пометить эти блоки плашкой «не для распространения вне Global ERP».

##### IntelliJ IDEA

`2.1.4` — путь `File | Settings | Editor | Code Style | Scala` для настройки порога импортов. IDE в курсе не рассматривается, тема раздела 8.

##### sbt

`1.1.1` — «инструменты, например sbt-scala3-migrate». Сборка — раздел 8.2.1, не написан.

##### Cats
