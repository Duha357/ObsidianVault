# Типы-произведения в Scala

---

## Тип-произведение как логическое «И»

Тип-произведение объединяет несколько значений в одно составное значение.

Интуитивно:

Если тип A и тип B объединены в произведение, значение содержит A И B одновременно.

Формально:

Если у нас есть типы:

- A
    
- B
    

то тип-произведение A × B содержит данные обоих типов.

Пример (логическое «И»):

val bookInfo: (String, Int) = ("Dune", 1965)

Значение содержит:

- имя И возраст.
    

Без одного из элементов значение невозможно.

---

## Кортежи (Tuples)

### Назначение

Кортеж — это простой способ объединить несколько разнородных значений без объявления собственного класса.

Scala поддерживает Tuple2, Tuple3, … до произвольной арности (в Scala 3 — без фиксированного ограничения).

Синтаксис:

val authorInfo: (String, Int) = ("Tolkien", 81)

Это сокращение для Tuple2[String, Int].

---

### Доступ к элементам

В классическом виде:

authorInfo._1  // "Tolkien"  
authorInfo._2  // 81

В Scala 3 дополнительно поддерживается деструктуризация:

val (authorName, authorAge) = authorInfo

Это предпочтительный способ работы с кортежами.

---

### Когда использовать кортежи

Кортежи уместны:

- для временных значений;
    
- при возврате нескольких результатов из функции;
    
- в простых локальных вычислениях.
    

Не рекомендуется использовать кортежи в публичных API, где важна семантика полей.

---

## Case-классы как именованные типы-произведения

Кортежи объединяют данные позиционно. Case-классы объединяют данные именованно.

Пример:

case class Book(title: String, pages: Int)

Создание экземпляра:

val book = Book("The Hobbit", 310)

Обратите внимание: new не требуется.

---

### Что делает case-класс

Case-класс автоматически генерирует:

- equals
    
- hashCode
    
- toString
    
- методы доступа к полям
    
- метод copy
    
- поддержку pattern matching
    

Пример:

val firstBook = Book("Dune", 500)  
val secondBook = Book("Dune", 500)  
  
firstBook == secondBook // true

Сравнение происходит по значению, а не по ссылке.

---

### Неизменяемость

Поля case-класса по умолчанию объявлены как val.

Это означает:

- неизменяемость состояния;
    
- безопасность при параллельном использовании;
    
- предсказуемость поведения.
    

Изменение данных осуществляется через copy:

val updatedBook = book.copy(pages = 320)

Создаётся новый объект.

---

## Сравнение кортежей и case-классов

  

|   |   |   |
|---|---|---|
|Характеристика|Кортеж|Case-класс|
|Именованные поля|Нет|Да|
|Семантика|Позиционная|Явная|
|Поддержка pattern matching|Да|Да|
|Подходит для публичного API|Нет|Да|

## Рекомендации по размеру

  

|   |   |   |
|---|---|---|
|Размер кортежа|Лучше использовать|Причина|
|1-3 поля|Кортеж|Быстро, удобно для временных структур|
|4-5 поля|Case-class|Читаемость, именованные поля|
|>5 полей|Case-class|Кортеж становится нечитаемым|
