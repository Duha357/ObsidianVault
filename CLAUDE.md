# Claude-специфика

Всё общее — правила, репозитории, конвенции, карта знаний, процедуры — в `AGENTS.md` (импортирован выше). Здесь только механика Claude Code.

## Правила

- Канон — `.agents/*`
- Все `.claude` файлы, обнаруживаются через junctions:
	- `.claude/skills` → `.agents/skills`
	- `.claude/rules` → `.agents/rules`
- Создание/Изменения/Удаления, предназначенные для `.claude/*`, делать в `.agents/*`
- Разрешения/Ограничения для `.claude/*`, работают для `.agents/*`

. Через junction это одни и те же файлы, редактируй смело по любому пути.
